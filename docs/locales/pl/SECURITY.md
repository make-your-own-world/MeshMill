# Polityka bezpieczeństwa

## Obsługiwane wersje

Poprawki bezpieczeństwa zostały zastosowane w najnowszej opublikowanej wersji MeshMill.

## Zgłaszanie luki

Użyj funkcji raportowania prywatnych luk w zabezpieczeniach GitHub, jeśli jest ona włączona dla repozytorium. Nie
obejmują prywatne pliki siatki, dane uwierzytelniające, dzienniki diagnostyczne lub dane osobowe, chyba że tak jest
wymagane do odtworzenia problemu, a ich ujawnienie zostało wyraźnie zatwierdzone.

Podaj wersję, której dotyczy problem, system operacyjny, etapy odtwarzania i oczekiwany wpływ. Publiczne
problemy są odpowiednie dla zwykłych błędów, które nie ujawniają danych ani nie tworzą granic bezpieczeństwa
porażka.
