# Καταγραφή αλλαγών

Όλες οι αξιοσημείωτες αλλαγές έκδοσης τεκμηριώνονται εδώ.

## 0.1.0

- Συνδέθηκε το κουμπί GitHub της εφαρμογής στο αποθετήριο MeshMill.
- Προστέθηκαν οι σύνδεσμοι GitHub και Buy Me a Coffee στο παράθυρο διαλόγου Πληροφορίες.
- Προστέθηκε τοπική φόρτωση, επιθεώρηση, επιλογή, περικοπή, διαγραφή, βελτιστοποίηση και εξαγωγή STL.
- Προστέθηκε Fast QEM, βελτιστοποίηση ισορροπημένης πυκνότητας, διατήρησης σχήματος και διατήρησης τοπολογίας.
- Προστέθηκαν λειτουργίες απεικόνισης σκιασμένου, πυκνότητας, καλωδίου και κορυφής.
- Προστέθηκαν ακυρώσιμες λειτουργίες παρασκηνίου, συγκρίσεις προσωρινής αποθήκευσης, αναίρεση και επανάληψη.
- Προστέθηκε βαθμονόμηση τυπικής προβολής με ζευγοποιημένες αντίθετες προβολές και διαμορφώσιμες συντομεύσεις.
- Προστέθηκε προκαταρκτική μνήμη μεγάλου πλέγματος και φόρτωση οριοθετημένης επισκόπησης.
- Προστέθηκαν μετρήσεις απόδοσης Windows, φορητή συσκευασία, συσκευασία εγκαταστάτη και λειτουργία CLI.
- Προστέθηκαν κατάλογοι τοπικής προσαρμογής και εργαλεία συνεργατών για μελλοντικές μεταφράσεις.
