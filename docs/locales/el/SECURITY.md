# Πολιτική ασφαλείας

## Υποστηριζόμενες εκδόσεις

Οι διορθώσεις ασφαλείας εφαρμόζονται στην πιο πρόσφατη δημοσιευμένη έκδοση MeshMill.

## Αναφορά ευπάθειας

Χρησιμοποιήστε τη δυνατότητα ιδιωτικής αναφοράς ευπάθειας του GitHub όταν είναι ενεργοποιημένη για το αποθετήριο. Μη
περιλαμβάνουν ιδιωτικά αρχεία πλέγματος, διαπιστευτήρια, αρχεία καταγραφής διαγνωστικών στοιχείων ή προσωπικές πληροφορίες, εκτός εάν είναι
απαιτείται για την αναπαραγωγή του θέματος και η αποκάλυψή τους έχει ρητά εγκριθεί.

Συμπεριλάβετε την επηρεαζόμενη έκδοση, το λειτουργικό σύστημα, τα βήματα αναπαραγωγής και τον αναμενόμενο αντίκτυπο. Δημόσιο
Τα ζητήματα είναι κατάλληλα για συνηθισμένα σφάλματα που δεν εκθέτουν δεδομένα ή δεν δημιουργούν όριο ασφαλείας
αποτυχία.
