# Συμβάλλοντας

Οι συνεισφορές είναι ευπρόσδεκτες μέσω προβλημάτων και αιτημάτων έλξης.

## Πεδίο εφαρμογής του έργου

Το MeshMill κάνει τα μεγάλα, πυκνά ή δύσκολα αρχεία πλέγματος διαχειρίσιμα για επεξεργασία κατάντη και
ροές εργασιών παραγωγής. Οι συνεισφορές θα πρέπει να βελτιώσουν την επιθεώρηση γεωμετρίας, το πλέγμα και την πυκνότητα του σημείου
διαχείριση, βελτιστοποίηση, επιλογή, περικοπή, εκκαθάριση, επικύρωση, ανταλλαγή STL, απόδοση,
ή τον συντονισμό αυτών των επιχειρήσεων.

Το έργο δεν περιλαμβάνει μοντελοποίηση γενικής χρήσης, γλυπτική, ζωγραφική, κινούμενα σχέδια, απόδοση,
σύνθεση σκηνής, υλικά, αρματωσιές ή άλλα συστήματα δημιουργίας περιεχομένου. Προτάσεις που εισάγουν
αυτά τα χαρακτηριστικά είναι εκτός του πεδίου εφαρμογής του έργου.

Οι νέες δυνατότητες θα πρέπει να κρατούν την εφαρμογή εστιασμένη, να διατηρούν άμεσες ροές εργασίας που μετατρέπουν την πηγή
γεωμετρία σε διαχειρίσιμα πλέγματα και αποφύγετε τη μετατροπή των υποστηρικτικών στοιχείων ελέγχου σε γενική επεξεργασία
περιβάλλον.

## Εντοπισμός

Το κείμενο προέλευσης της αγγλικής διεπαφής χρήστη αποθηκεύεται στο `locales/en-US.json`. Τα τοπικά μεταδεδομένα αποθηκεύονται σε
`locales/manifest.json`. Οι μεταφρασμένοι κατάλογοι διεπαφής χρήστη χρησιμοποιούν τα ίδια σταθερά κλειδιά και το όνομα αρχείου
`<locale>.json`. Η μεταφρασμένη τεκμηρίωση χρησιμοποιεί το αντίστοιχο όνομα αρχείου ρίζας κάτω από
`docs/locales/<locale>/`.

Οι μεταφράσεις παράγονται αρχικά με εξωτερικές υπηρεσίες μηχανικής μετάφρασης και παραλαμβάνονται
αυτοματοποιημένη δομική επικύρωση. Αυτή η διαδικασία δεν μπορεί να εγγυηθεί φυσικά, τεχνικά ακριβή ή
ορθή γλώσσα από τα συμφραζόμενα. Οι φυσικοί ομιλητές ενθαρρύνονται να ελέγχουν και να διορθώνουν τη μεταφρασμένη διεπαφή χρήστη
κείμενο και τεκμηρίωση. Οι διορθώσεις μετάφρασης θα πρέπει να διατηρούν τα κλειδιά καταλόγου, τα σύμβολα κράτησης θέσης,
εντολές, συνδέσμους, μετρήσεις, ονόματα προϊόντων και δομή Markdown.

Αφού αλλάξετε τις ετικέτες, τις συμβουλές εργαλείων, τα παράθυρα διαλόγου ή άλλο κείμενο ορατό από τον χρήστη, εκτελέστε:

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
```

Ελέγξτε μαζί τις αλλαγές πηγής και τα αναδημιουργημένα κλειδιά.

## Αλλαγές γεωμετρίας και αλγορίθμου

Χρησιμοποιήστε τη ομαδοποιημένη γεωμετρία του δείγματος κατά την αλλαγή της βελτιστοποίησης, της ανάλυσης πυκνότητας, της επιλογής, της περικοπής,
χειρισμός μεγάλων αρχείων ή συμπεριφορά σύγκρισης θυρών προβολής. Περιέχει σκόπιμα περιττά στρώματα
και ανομοιόμορφη πυκνότητα, επομένως ένα χρήσιμο αποτέλεσμα θα πρέπει να βελτιώνει τη διαχειρισιμότητα χωρίς να κρύβει παραμόρφωση,
απόρριψη σημαντικών ορίων ή σιωπηλή κατάργηση της γεωμετρίας που διατηρεί ένας άλλος αλγόριθμος.

Καταγράψτε την είσοδο, τον αλγόριθμο, τις ρυθμίσεις, τον αριθμό τριγώνων, τις διαστάσεις, τη μετατόπιση διαστάσεων, τον χρόνο που έχει παρέλθει,
και σχετικά στιγμιότυπα οθόνης για συγκρίσεις. Δοκιμάστε τόσο το μικρότερο κανονικό εξάρτημα Git όσο και όταν το
Η αλλαγή αφορά μεγάλη ή πολυεπίπεδη γεωμετρία, το αρχικό εξάρτημα Git LFS. Μην συντονίζετε έναν αλγόριθμο
μόνο σε αυτό το εξάρτημα. Προσθέστε μικρές συνθετικές θήκες για το συγκεκριμένο αμετάβλητο ή παλινδρομικό ον
δοκιμασμένο.

Δείτε [Δοκιμή και συνεισφορά αλγορίθμου](docs/ALGORITHM_TESTING.md) για τη λίστα ελέγχου σύγκρισης.

## Ρύθμιση ανάπτυξης

1. Εγκαταστήστε το 64-bit Python 3.12 στο Windows.
2. Δημιουργήστε και ενεργοποιήστε ένα εικονικό περιβάλλον.
3. Εγκαταστήστε το `requirements-dev.txt`.
4. Εκτελέστε το `python meshmill.py` για το GUI ή το `python meshmill.py --help` για χρήση CLI.
5. Εκτελέστε το `python -m py_compile meshmill.py` πριν υποβάλετε μια αλλαγή.

Διατηρήστε ιδιωτικά πλέγματα, εκτελέσιμα που δημιουργούνται, στιγμιότυπα οθόνης που περιέχουν ιδιωτικές πληροφορίες και τοπικά
δημιουργία καταλόγων από δεσμεύσεις. Η αναδιανεμόμενη γεωμετρία δοκιμής ανήκει στο `samples/` μαζί της
τεκμηριωμένη πηγή, άδεια, διαστάσεις και μέθοδος παραγωγής. Τα νέα αρχεία προέλευσης θα πρέπει να χρησιμοποιούν το
Αναγνωριστικό SPDX `GPL-3.0-or-later`.

Περικόψτε κάθε στιγμιότυπο οθόνης τεκμηρίωσης στο περιεχόμενο της εφαρμογής MeshMill. Μην συμπεριλάβετε το
γραμμή εργασιών, άσχετο παράθυρο chrome, ειδοποιήσεις, στοιχεία λογαριασμού, ιδιωτικές διαδρομές ή φόντο
περιεχόμενο επιφάνειας εργασίας.
