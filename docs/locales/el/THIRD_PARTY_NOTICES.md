# Λογισμικό τρίτων κατασκευαστών

Το MeshMill εξαρτάται από το ακόλουθο λογισμικό. Αυτά τα στοιχεία διατηρούν τις δικές τους άδειες και
ειδοποιήσεις πνευματικών δικαιωμάτων.

| Εξάρτημα | Έκδοση | Άδεια |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Software Foundation License |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-Clause και ομαδικές επιτρεπτές άδειες |
| [γρήγορη απλοποίηση](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Ρήτρα |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | Μόνο για LGPL-3.0, μόνο για GPL-2.0 ή μόνο για GPL-3.0 |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | Μόνο για LGPL-3.0, μόνο για GPL-2.0 ή μόνο για GPL-3.0 |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 ή νεότερη έκδοση με εξαίρεση του bootloader |

Το πακέτο Windows διανέμει τα PySide6 και Shiboken6 κάτω από την επιλογή GPL-3.0, με συνέπεια
με άδεια GPL-3.0 ή νεότερη έκδοση του MeshMill. Οι τροχοί NumPy περιέχουν επιπλέον επιτρεπτά άδεια
εξαρτήματα? Οι ειδοποιήσεις τους περιλαμβάνονται στα εγκατεστημένα μεταδεδομένα του πακέτου και θα πρέπει να διατηρηθούν
κατά την αναδιανομή μιας τροποποιημένης δυαδικής δέσμης.
