# Υποστήριξη της ανεξάρτητης ανάπτυξης

Είμαι ανεξάρτητος προγραμματιστής που του αρέσει να λύνει πρακτικά προβλήματα με λογισμικό ανοιχτού κώδικα. Οι περισσότεροι
των έργων μου ξεκινούν επειδή χρειάζομαι ένα καλύτερο εργαλείο ο ίδιος και μετά εξελίσσομαι σε κάτι χρήσιμο για άλλους
ανθρώπους.

Επικεντρώνομαι στη δημιουργία αξιόπιστου, αυτο-φιλοξενούμενου και φιλικού προς τον αυτοματισμό λογισμικού που εξοικονομεί χρόνο,
μειώνει την πολυπλοκότητα και βοηθά τα υπάρχοντα συστήματα να συνεργάζονται καλύτερα. Χτίζοντας πράγματα που βοηθούν
οι άνθρωποι είναι αυτό που με οδηγεί. Αισθάνομαι ότι είμαι εδώ για να κάνω τον χρόνο μου σε αυτόν τον βράχο.

Αυτά τα έργα απαιτούν χρόνο, χρήμα και ενέργεια παράλληλα με την εργασία και την καθημερινή ζωή. Αν έχετε βρει
κάτι που έχω δημιουργήσει χρήσιμο, η υποστήριξή σας βοηθά στην κάλυψη του χρόνου ανάπτυξης, δοκιμών υλικού, φιλοξενίας,
και το συνεχές έργο διατήρησης και βελτίωσής του.

Η υποστήριξη μπορεί να λάβει πολλές μορφές. Κοινή χρήση ενός έργου, αναφορά σφάλματος, συνεισφορά σε μια επιδιόρθωση ή βοήθεια
κάποιος άλλος επιδιώκει τη δική του κλήση, όλα κάνουν τη διαφορά. Υπάρχουν άνθρωποι που ελκύονται από τα μαθηματικά,
χημεία, μηχανική, τέχνη και αμέτρητα άλλα πεδία που θα μπορούσαν να χρησιμοποιήσουν λίγη βοήθεια για να κάνουν τη δουλειά
έχουν ήδη αναγκαστεί να το κάνουν.

Το unboxing βίντεο και οι αντιδράσεις έχουν τη θέση τους, αλλά χρειαζόμαστε επίσης ανθρώπους που κάνουν τα πράγματα να αξίζουν
άνοιγμα, ιδέες στις οποίες αξίζει να αντιδράσουμε και ανακαλύψεις που μας οδηγούν μπροστά. Ελπίζω η δουλειά μου να βοηθήσει
κάποιος κάνει λίγο περισσότερο από αυτό, και ότι μπορεί να περάσει αυτή τη βοήθεια.

δημιουργούν.
