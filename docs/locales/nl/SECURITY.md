# Beveiligingsbeleid

## Ondersteunde versies

Er zijn beveiligingsoplossingen toegepast op de laatst gepubliceerde MeshMill-release.

## Een kwetsbaarheid melden

Gebruik de functie voor het rapporteren van privékwetsbaarheden van GitHub wanneer deze is ingeschakeld voor de repository. Niet doen
privé-mesh-bestanden, inloggegevens, diagnostische logbestanden of persoonlijke informatie bevatten, tenzij dit het geval is
vereist om het probleem te reproduceren en de openbaarmaking ervan is uitdrukkelijk goedgekeurd.

Vermeld de getroffen versie, het besturingssysteem, de reproductiestappen en de verwachte impact. Openbaar
problemen zijn geschikt voor gewone bugs die geen gegevens vrijgeven of een beveiligingsgrens creëren
mislukking.
