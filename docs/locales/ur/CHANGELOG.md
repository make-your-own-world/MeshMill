# چینج لاگ

تمام قابل ذکر ریلیز تبدیلیاں یہاں دستاویزی ہیں۔

## 0.1.0

- ایپلیکیشن GitHub بٹن کو MeshMill ریپوزٹری سے منسلک کیا۔
- کے بارے میں ڈائیلاگ میں GitHub اور Buy Me a Coffee لنکس کو شامل کیا۔
- مقامی STL لوڈنگ، معائنہ، انتخاب، کٹائی، حذف، اصلاح، اور برآمد کو شامل کیا گیا۔
- شامل کیا گیا Fast QEM، کثافت متوازن، شکل کو محفوظ رکھنے، اور ٹوپولوجی کو محفوظ کرنے والی اصلاح۔
- سایہ دار، کثافت، وائر فریم، اور ورٹیکس ڈسپلے موڈز شامل کیے گئے۔
- منسوخ کیے جانے والے پس منظر کے آپریشنز، کیشڈ موازنہ، کالعدم اور دوبارہ کرنا شامل کیا گیا۔
- جوڑا بنائے گئے مخالف نظاروں اور قابل ترتیب شارٹ کٹس کے ساتھ معیاری منظر کیلیبریشن شامل کی گئی۔
- بڑی میش میموری پری فلائٹ اور باؤنڈڈ اوور ویو لوڈنگ شامل کی گئی۔
- Windows پرفارمنس میٹرکس، پورٹیبل پیکیجنگ، انسٹالر پیکیجنگ، اور CLI آپریشن شامل کیا گیا۔
- مستقبل کے تراجم کے لیے لوکلائزیشن کیٹلاگ اور معاون ٹولنگ کو شامل کیا گیا۔
