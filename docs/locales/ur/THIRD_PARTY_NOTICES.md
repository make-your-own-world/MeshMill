# تھرڈ پارٹی سافٹ ویئر

MeshMill درج ذیل سافٹ ویئر پر منحصر ہے۔ یہ اجزاء اپنے لائسنس کو برقرار رکھتے ہیں اور
کاپی رائٹ نوٹس

| جزو | ورژن | لائسنس |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python سافٹ ویئر فاؤنڈیشن لائسنس |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-شق اور بنڈل اجازت نامہ |
| [تیزی سے آسان بنانے](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Clause |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0-only, GPL-2.0-only, or GPL-3.0-only |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0-only, GPL-2.0-only, or GPL-3.0-only |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0-یا بعد میں بوٹ لوڈر کی رعایت کے ساتھ |

Windows بنڈل PySide6 اور Shiboken6 کو اپنے GPL-3.0 آپشن کے تحت، مستقل طور پر تقسیم کرتا ہے۔
MeshMill کے GPL-3.0-یا بعد کے لائسنس کے ساتھ۔ NumPy پہیوں میں اجازت کے ساتھ لائسنس یافتہ اضافی ہوتے ہیں۔
اجزاء؛ ان کے نوٹس انسٹال شدہ پیکج میٹا ڈیٹا میں شامل ہیں اور انہیں برقرار رکھا جانا چاہیے۔
ترمیم شدہ بائنری بنڈل کو دوبارہ تقسیم کرتے وقت۔
