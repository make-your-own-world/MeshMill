# تعاون کرنا

ایشوز اور پل کی درخواستوں کے ذریعے تعاون کا خیرمقدم کیا جاتا ہے۔

## پروجیکٹ کا دائرہ کار

MeshMill بڑے، گھنے، یا مشکل میش فائلوں کو نیچے کی طرف سے ترمیم کرنے کے قابل بناتا ہے اور
پیداوار کے کام کے بہاؤ. شراکت کو جیومیٹری معائنہ، میش اور پوائنٹ کی کثافت کو بہتر بنانا چاہیے۔
انتظام، اصلاح، انتخاب، تراشنا، صفائی، توثیق، STL تبادلہ، کارکردگی،
یا ان آپریشنز کی کوآرڈینیشن۔

پروجیکٹ میں عام مقصد کی ماڈلنگ، مجسمہ سازی، پینٹنگ، اینیمیشن، رینڈرنگ،
منظر کی ساخت، مواد، دھاندلی، یا دیگر مواد کی تخلیق کے نظام۔ تجاویز جو متعارف کراتے ہیں۔
وہ خصوصیات منصوبے کے دائرہ کار سے باہر ہیں۔

نئی خصوصیات کو ایپلیکیشن کو فوکس رکھنا چاہیے، براہ راست ورک فلو کو محفوظ رکھنا چاہیے جو سورس بنتے ہیں۔
جیومیٹری کو قابل انتظام میشوں میں تبدیل کریں، اور معاون کنٹرول کو عام ترمیم میں تبدیل کرنے سے گریز کریں۔
ماحول

## لوکلائزیشن

انگریزی UI سورس ٹیکسٹ `locales/en-US.json` میں محفوظ ہے۔ لوکل میٹا ڈیٹا اس میں محفوظ ہے۔
`locales/manifest.json` ترجمہ شدہ UI کیٹلاگ ایک ہی مستحکم کلید اور فائل کا نام استعمال کرتے ہیں۔
`<locale>.json` ترجمہ شدہ دستاویزات کے تحت مماثل روٹ فائل کا نام استعمال کرتا ہے۔
`docs/locales/<locale>/`

لیبلز، ٹول ٹِپس، ڈائیلاگز، یا صارف کے نظر آنے والے دوسرے متن کو تبدیل کرنے کے بعد، چلائیں:

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
```

ماخذ کی تبدیلیوں اور دوبارہ تخلیق شدہ کلیدوں کا ایک ساتھ جائزہ لیں۔

## جیومیٹری اور الگورتھم میں تبدیلیاں

اصلاح، کثافت تجزیہ، انتخاب، کٹائی، تبدیل کرتے وقت بنڈل نمونہ جیومیٹری کا استعمال کریں
بڑی فائل ہینڈلنگ، یا ویو پورٹ کے مقابلے کا رویہ۔ یہ جان بوجھ کر بے کار تہوں پر مشتمل ہے۔
اور ناہموار کثافت، لہذا ایک مفید نتیجہ مسخ کو چھپائے بغیر نظم و نسق کو بہتر بنائے،
معنی خیز حدود کو ترک کرنا، یا خاموشی سے جیومیٹری کو ہٹانا جسے کوئی اور الگورتھم محفوظ رکھتا ہے۔

ان پٹ، الگورتھم، ترتیبات، مثلث کی گنتی، طول و عرض، طول و عرض، گزرے ہوئے وقت کو ریکارڈ کریں،
اور موازنہ کے لیے متعلقہ اسکرین شاٹس۔ دونوں چھوٹے نارمل-گٹ فکسچر کی جانچ کریں اور، جب
تبدیلی کے خدشات بڑے یا تہہ دار جیومیٹری، اصل Git LFS فکسچر۔ الگورتھم کو ٹیون نہ کریں۔
اکیلے اس فکسچر کے لئے. مخصوص انویریئنٹ یا ریگریشن وجود کے لیے چھوٹے مصنوعی کیسز شامل کریں۔

## ترقیاتی سیٹ اپ

1. Windows پر 64-bit Python 3.12 انسٹال کریں۔
2. ایک مجازی ماحول بنائیں اور فعال کریں۔
3. `requirements-dev.txt` انسٹال کریں۔
4. GUI کے لیے `python meshmill.py` یا CLI کے استعمال کے لیے `python meshmill.py --help` چلائیں۔
5. تبدیلی جمع کرانے سے پہلے `python -m py_compile meshmill.py` چلائیں۔

پرائیویٹ میشز، جنریٹڈ ایگزیکیوٹیبلز، پرائیویٹ معلومات پر مشتمل اسکرین شاٹس اور مقامی رکھیں
کمٹوں سے ڈائریکٹریز بنائیں۔ دوبارہ تقسیم کرنے کے قابل ٹیسٹ جیومیٹری کا تعلق اس کے ساتھ `samples/` کے تحت ہے۔
ماخذ، لائسنس، طول و عرض، اور نسل کا طریقہ دستاویزی ہے۔ نئی سورس فائلوں کو استعمال کرنا چاہئے۔
