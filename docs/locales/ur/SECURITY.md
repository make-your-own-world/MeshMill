# سیکیورٹی پالیسی

## تائید شدہ ورژن

تازہ ترین شائع شدہ MeshMill ریلیز پر سیکیورٹی اصلاحات کا اطلاق ہوتا ہے۔

## خطرے کی اطلاع دینا

GitHub کی نجی خطرے کی اطلاع دینے والی خصوصیت کا استعمال کریں جب یہ ریپوزٹری کے لیے فعال ہو۔ مت کرو
نجی میش فائلیں، اسناد، تشخیصی لاگز، یا ذاتی معلومات شامل کریں جب تک کہ وہ نہ ہوں
مسئلہ کو دوبارہ پیش کرنے کی ضرورت ہے اور ان کے انکشاف کو واضح طور پر منظور کر لیا گیا ہے۔

متاثرہ ورژن، آپریٹنگ سسٹم، تولیدی مراحل، اور متوقع اثر شامل کریں۔ عوامی
ایشوز عام کیڑے کے لیے موزوں ہیں جو ڈیٹا کو ظاہر نہیں کرتے یا سیکیورٹی باؤنڈری نہیں بناتے ہیں۔
