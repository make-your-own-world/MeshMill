# خرابی کا سراغ لگانا

## Windows ڈاؤن لوڈ کو روکتا ہے۔

غیر دستخط شدہ کمیونٹی کی تعمیرات Microsoft Defender SmartScreen کو متحرک کر سکتی ہیں۔ ڈاؤن لوڈ کردہ کا موازنہ کریں۔
اسی GitHub ریلیز سے `SHA256SUMS.txt` کے ساتھ فائل کا SHA-256 ہیش۔ دستخط شدہ ریلیز کی شناخت
Windows فائل کی خصوصیات میں ان کا پبلشر۔

## پورٹیبل تعمیر شروع نہیں ہوتا ہے۔

`MeshMill.exe` چلانے سے پہلے مکمل زپ نکالیں۔ `_internal` ڈائرکٹری اگلی رہنی چاہیے۔
دونوں ایگزیکیوٹیبلز کے لیے۔ زپ ویور کے اندر سے ایگزیکیوٹیبل نہ چلائیں۔

## ایک بڑا STL ایک جائزہ کے طور پر کھلتا ہے۔

تخمینہ شدہ ورکنگ سیٹ سیٹنگز میں میموری بجٹ سے زیادہ ہے۔ جائزہ موڈ جان بوجھ کر ہے۔
صرف پڑھنے کے لیے۔ بجٹ میں صرف اس وقت اضافہ کریں جب مشین میں کافی میموری موجود ہو، یا کم کریں۔
اسے ترمیم کے لیے کھولنے سے پہلے میش کریں۔

## ایک معیاری منظر محفوظ نہیں کیا گیا تھا۔

Ctrl میں ترمیم شدہ ویو شارٹ کٹ دبائیں، پھر **محفوظ کریں** کا انتخاب کریں یا تصدیق میں Enter دبائیں
ڈائیلاگ ایک منظر کو محفوظ کرنے سے اس کے برعکس بھی اپ ڈیٹ ہوجاتا ہے۔ اسٹیٹس لائن محفوظ شدہ منظر کی اطلاع دیتی ہے۔

## نیویگیشن شارٹ کٹ جواب نہیں دیتے

پہلے کوئی بھی موڈل ڈائیلاگ بند کریں۔ ترتیبات میں شارٹ کٹس کا جائزہ لیں یا دوبارہ ترتیب دیں اگر وہ حسب ضرورت بنائے گئے تھے۔ دی
ڈیفالٹ ویو شارٹ کٹ Insert، Home، Page Up، Delete، End، اور Page Down کا استعمال کرتے ہیں۔

## ایک مقامی واقفیت تشخیصی لاگ بنائیں

تشخیصی لاگنگ بطور ڈیفالٹ غیر فعال ہے۔ مقامی طور پر کی بورڈ روٹنگ اور کیمرے کی حالت کو ریکارڈ کرنے کے لیے:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

لاگ میں کھلا ہوا فائل پاتھ ہو سکتا ہے۔ شیئر کرنے سے پہلے اس کا جائزہ لیں اور اس کی اصلاح کریں۔ میش جیومیٹری نہیں ہے۔
لاگ پر لکھا گیا۔

## کسی مسئلے کی اطلاع دیں۔

MeshMill ورژن، Windows ورژن، GPU ماڈل، میش مثلث شمار، عین مطابق کارروائی شامل کریں
ترتیب، اور آیا انسٹالر یا پورٹیبل پیکیج استعمال کیا گیا تھا۔ دوبارہ تقسیم کرنے والا نمونہ استعمال کریں۔
جب ممکن ہو میش. پہلے ان کا جائزہ لیے بغیر پرائیویٹ اسکینز یا تشخیصی لاگز منسلک نہ کریں۔
