# তৃতীয় পক্ষের সফটওয়্যার

MeshMill নিম্নলিখিত সফ্টওয়্যারের উপর নির্ভর করে। এই উপাদানগুলি তাদের নিজস্ব লাইসেন্স বজায় রাখে এবং
কপিরাইট নোটিশ

| উপাদান | সংস্করণ | লাইসেন্স |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python সফটওয়্যার ফাউন্ডেশন লাইসেন্স |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-ধারা এবং বান্ডিল অনুমতিমূলক লাইসেন্স |
| [দ্রুত-সরলীকরণ](https://github.com/pyvista/fast-simplification) | 0.2.0 | এমআইটি |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-ধারা |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | শুধুমাত্র LGPL-3.0, GPL-2.0-only, অথবা GPL-3.0-only |
| [শিবোকেন6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | শুধুমাত্র LGPL-3.0, GPL-2.0-only, অথবা GPL-3.0-only |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | একটি বুটলোডার ব্যতিক্রম সহ GPL-2.0-বা পরে |

Windows বান্ডেল তাদের GPL-3.0 বিকল্পের অধীনে PySide6 এবং Shiboken6 বিতরণ করে, সামঞ্জস্যপূর্ণ।
MeshMill-এর GPL-3.0-বা-পরবর্তী লাইসেন্স সহ। NumPy চাকার অতিরিক্ত অনুমতিমূলক লাইসেন্স ধারণ করে
উপাদান; তাদের নোটিশ ইনস্টল করা প্যাকেজ মেটাডেটা অন্তর্ভুক্ত করা হয়েছে এবং বজায় রাখা উচিত
একটি পরিবর্তিত বাইনারি বান্ডিল পুনরায় বিতরণ করার সময়।
