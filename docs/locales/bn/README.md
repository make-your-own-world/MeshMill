# MeshMill

![MeshMill শেডেড ভিউপোর্ট](../../images/meshmill-shaded.png)

MeshMill হলো একটি বিশেষায়িত ডেস্কটপ অ্যাপ্লিকেশন যা অত্যন্ত বড় আকারের, ঘন বা জটিল মেশ জ্যামিতিকে
সহজভাবে পরিচালনাযোগ্য করে তোলে। এটি দ্রুত পরিদর্শন, ঘনত্ব বিশ্লেষণ, নির্দিষ্ট অংশ নির্বাচন, ক্রপিং, মুছে ফেলা,
এবং কোনো অ্যাকাউন্ট তৈরি বা জ্যামিতি আপলোড করার প্রয়োজন ছাড়াই নিয়ন্ত্রিতভাবে মেশের আকার কমানোর (mesh reduction) সুবিধা দেয়।

MeshMill বিভিন্ন উৎস থেকে প্রাপ্ত মেশ নিয়ে কাজ করতে পারে, যেমন—থ্রিডি (3D) স্ক্যানার, CAD ও মডেলিং এক্সপোর্ট ফাইল, রিকনস্ট্রাকশন পাইপলাইন,
জেনারেটেড জ্যামিতি এবং অন্যান্য STL উৎস। এটি পরবর্তী ধাপের এডিটর,
ম্যানুফ্যাকচারিং টুল এবং অন্যান্য মেশ-ভিত্তিক কাজের প্রক্রিয়ার জন্য জ্যামিতিকে প্রস্তুত করে। সাধারণ মডেলিং, স্কাল্পটিং, অ্যানিমেশন,
ম্যাটেরিয়াল এবং দৃশ্য (scene) তৈরির কাজ এর আওতাভুক্ত নয়।

## ডাউনলোড

[GitHub রিলিজ](../../releases) থেকে নিচের যেকোনো একটি ফাইল ডাউনলোড করুন:

- `MeshMill-<version>-windows-x64-setup.exe`: প্রতি-ব্যবহারকারী (per-user) ইনস্টলার, যাতে স্টার্ট মেনু এবং ঐচ্ছিক
  ডেস্কটপ শর্টকাটের সুবিধা রয়েছে।
- `MeshMill-<version>-windows-x64-portable.zip`: পোর্টেবল অ্যাপ্লিকেশন। সম্পূর্ণ আর্কাইভটি এক্সট্র্যাক্ট বা আনজিপ করুন,
  তারপর `MeshMill.exe` চালান।

উভয় প্যাকেজেই অ্যাপ্লিকেশন রানটাইম অন্তর্ভুক্ত রয়েছে। সাধারণ ব্যবহারকারীরা Python, Node.js বা
ডিপেন্ডেন্সিগুলো (dependencies) ইনস্টল করেন না। প্রাথমিক সংস্করণে x64 হার্ডওয়্যারে Windows 10 এবং Windows 11 সমর্থিত। Linux এবং
macOS প্যাকেজগুলো আনার পরিকল্পনা রয়েছে; পণ্য এবং ফাইলের ফরম্যাটগুলো নির্দিষ্টভাবে Windows-এর জন্য নয়।

স্বাক্ষরবিহীন কমিউনিটি বিল্ডগুলোর ক্ষেত্রে Windows SmartScreen সতর্কতা দেখা যেতে পারে। রিলিজ চেকসামগুলো তালিকাভুক্ত করা হয়েছে
প্রতিটি রিলিজের পাশে `SHA256SUMS.txt`-এ।

## দ্রুত শুরু (Quick start)

1. একটি STL খুলুন।
2. Shaded, Density, Wireframe বা Vertices ডিসপ্লে মোডে এটি পরীক্ষা করুন।
3. কোয়ালিটি লেভেল, অ্যালগরিদম এবং টার্গেট ট্রায়াঙ্গেল কাউন্ট (ত্রিভুজের সংখ্যা) নির্বাচন করুন।
4. ফলাফল নির্ণয় করতে **Optimize** নির্বাচন করুন।
5. মূল এবং অপ্টিমাইজ করা মেশ (mesh)-এর তুলনা করুন, তারপর কাজটি কার্যকর করতে **Apply** নির্বাচন করুন।
6. **Save current state** নির্বাচন করুন অথবা `Ctrl+S` চাপুন।

শুধুমাত্র কোনো ফাইল বা সেটিংস পরিবর্তনের কারণে MeshMill কখনোই অপ্টিমাইজেশন প্রক্রিয়া শুরু করে না।

## ক্ষমতা ও সুবিধাসমূহ

- বাইনারি এবং ASCII STL ইনপুট, বাইনারি STL আউটপুট
- Fast QEM-এর ঘনত্ব-ভারসাম্যপূর্ণ, আকৃতি-অক্ষুণ্ণকারী এবং টপোলজি-অক্ষুণ্ণকারী সংকোচন (reduction)
- শেডেড (shaded), ঘনত্ব (density), ওয়্যারফ্রেম (wireframe) এবং ভার্টেক্স (vertex) ডিসপ্লে মোড
- ত্রিভুজের সংখ্যার কোনো নির্দিষ্ট সর্বোচ্চ সীমা (ceiling) নয়, বরং জ্যামিতিক কাঠামোর ওপর ভিত্তি করে স্বয়ংক্রিয় লক্ষ্যমাত্রা নির্ধারণ
- একাধিক অঞ্চল বা এলাকা যোগ করার সুবিধাসহ পলিগন নির্বাচন
- শুধুমাত্র নির্বাচিত অংশের ক্রপ, ডিলিট বা অপ্টিমাইজেশন
- ক্যাশ-এ সংরক্ষিত মূল, পূর্ববর্তী এবং বর্তমান মেশ (mesh)-এর মধ্যে তুলনা
- জ্যামিতিক কাঠামোয় করা পরিবর্তনগুলোর জন্য আনডু (undo) এবং রিডু (redo) সুবিধা
- মাত্রা বা ডাইমেনশনের বিচ্যুতি (drift), সংকোচনের হার এবং সম্ভাব্য আউটপুট সাইজ
- মিলিমিটার, সেন্টিমিটার, মিটার, ইঞ্চি এবং ফুট—এই এককগুলোতে প্রদর্শনের সুবিধা
- CPU, মেমরি, GPU এবং জ্যামিতিক-কার্যকলাপ সংক্রান্ত মেট্রিক্স
- বাইনারি STL ফাইল নির্ধারিত মেমরি সীমার (budget) চেয়ে বড় হলে সীমাবদ্ধ ওভারভিউ লোড করার ব্যবস্থা
- GUI এবং কমান্ড-লাইন অ্যাপ্লিকেশন
- অ্যাকাউন্ট, টেলিমেট্রি, আপলোড বা ক্লাউড-এর ওপর কোনো নির্ভরতা ছাড়াই স্থানীয়ভাবে প্রসেসিং

জোড়া থাকা। নিশ্চিতকরণ ডায়ালগে, **সংরক্ষণ** হল ডিফল্ট ক্রিয়া, তাই এন্টার সংরক্ষণ করে
অভিযোজন শীর্ষ এবং নীচের উভয় দৃশ্যের শীর্ষে সামনে প্রদর্শিত হয়৷

সেটিংসে শর্টকাট পরিবর্তন বা রিসেট করা যেতে পারে।

## নির্বাচন কর্মপ্রবাহ

একটি বহুভুজ আঁকতে Ctrl ধরে বাম-টেনে আনুন। এটিকে পুনরায় আকার দিতে কোণগুলি টেনে আনুন, একটি যুক্ত করতে একটি প্রান্তে বাম-ক্লিক করুন৷
পয়েন্ট, অথবা একটি সরাতে একটি প্রান্ত ডান ক্লিক করুন. `Ctrl+C` এর সাথে আরও অঞ্চল যোগ করুন। ক্যামেরা মুভিং হাইড
নির্বাচিত জ্যামিতি বজায় রাখার সময় স্ক্রীন-স্পেস বহুভুজ।

একটি সক্রিয় নির্বাচনের সাথে অপ্টিমাইজেশন শুধুমাত্র সেই নির্বাচনকে প্রভাবিত করে। ফলাফল অস্থায়ী থেকে যায়
যতক্ষণ না **আবেদন** নির্বাচন করা হয়। **বাতিল** অস্থায়ী ফলাফল বাতিল করে এবং তাই নির্বাচন বজায় রাখে
অন্য কনফিগারেশন চেষ্টা করা যেতে পারে। ক্রপ করা এবং মুছে ফেলার কাজগুলি স্বাভাবিক অপরিবর্তনীয় জাল সম্পাদনা হয়ে যায়।

## বড় জাল

একটি বাইনারি STL বরাদ্দ করার আগে, MeshMill কনফিগার করা সাথে তার আনুমানিক কাজের মেমরির তুলনা করে
মেমরি বাজেট। বাজেটের উপরে একটি ফাইল একটি আবদ্ধ, শুধুমাত্র-পঠন ওভারভিউ হিসাবে খোলে। ওভারভিউ রিপোর্ট
সম্পূর্ণ উৎস ত্রিভুজ গণনা কিন্তু সম্পাদনা এবং রপ্তানি অক্ষম করে কারণ এটি একটি নমুনা, সম্পূর্ণ নয়
বস্তু ইনডেক্সড, জুম-নির্ভর আউট-অফ-কোর প্রক্রিয়াকরণের পরিকল্পনা করা হয়েছে
[docs/OUT_OF_CORE.md](docs/OUT_OF_CORE.md)।

## কমান্ড লাইন

`MeshMillCLI.exe` উভয় রিলিজ প্যাকেজে অন্তর্ভুক্ত করা হয়েছে:

```powershell
.\MeshMillCLI.exe "C:\path\mesh.stl" --preset balanced
.\MeshMillCLI.exe "C:\path\mesh.stl" --target 150000 --output "C:\path\mesh-reduced.stl"
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm density --target 150000
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm topology --overwrite
```

সমস্ত বিকল্পের জন্য `.\MeshMillCLI.exe --help` চালান। MeshMill তার ইনপুট ফাইল ওভাররাইট করতে অস্বীকার করে।

## নমুনা জ্যামিতি

উন্নয়ন নমুনা দুটি সংস্করণ উপলব্ধ. নমুনা সঙ্গে একটি যৌগিক জাল
অপ্রয়োজনীয় জ্যামিতি এবং বিভিন্ন ঘনত্বের ইচ্ছাকৃত স্তর। এটি একটি স্ক্যানার ছাড়া মানুষ দেয়
অ্যালগরিদম তুলনা করার জন্য বাস্তবসম্মত ফিক্সচার, ঘনত্ব পরিদর্শন, আঞ্চলিক ক্রিয়াকলাপ অনুশীলন,
এবং রোডম্যাপ বৈশিষ্ট্য উন্নয়নশীল. MeshMill স্ক্যান করা ইনপুট প্রয়োজন নেই.

| ফাইল | ত্রিভুজ | আকার | ডেলিভারি | জন্য সেরা |
| --- | ---: | ---: | --- | --- |
| [`sample-scan.stl`](../../../samples/sample-scan.stl) | 249,999 | 11.9 MiB | সাধারণ গিট | দ্রুত মূল্যায়ন, CI, এবং নিয়ন্ত্রণ শেখা |
| [`original-scan.stl`](../../../samples/original-scan.stl) | 4,126,315 | 196.8 MiB | Git LFS | ঘন উৎস জ্যামিতি এবং বড়-জাল কর্মক্ষমতা পরীক্ষা করা হচ্ছে |

প্রতিটি সাধারণ ক্লোনের সাথে ছোট নমুনা ডাউনলোড করা হয়। অস্পর্শ মূল ঐচ্ছিক এবং
Git LFS এর মাধ্যমে পরিচালিত হয় তাই এটি সাধারণ সংগ্রহস্থলের ইতিহাসকে স্ফীত করে না। GitHub ডেস্কটপ অন্তর্ভুক্ত
Git LFS. কমান্ড-লাইন ব্যবহারকারীরা Git LFS ইনস্টল করতে এবং চালাতে পারেন:

```powershell
git lfs pull --include="samples/original-scan.stl"
```

ট্যাগ করা রিলিজগুলি আসল STL কে সরাসরি ডাউনলোড হিসাবে প্রকাশ করে যারা গিট ব্যবহার করে না।
মূল, মাত্রা এবং চেকসামগুলির জন্য [`samples/README.md`](../../../samples/README.md) দেখুন।

## STL ইউনিট

STL একটি ইউনিট এনকোড করে না। মডেল ইউনিট পরিবর্তন করা স্কেলিং ছাড়াই লেবেল এবং পরিমাপ পরিবর্তন করে
সংরক্ষিত স্থানাঙ্ক। উৎস জ্যামিতি বর্ণনা করে এমন ইউনিট নির্বাচন করুন।

## গোপনীয়তা

MeshMill স্থানীয় ফাইল পড়ে এবং লেখে। এতে কোনো অ্যাকাউন্ট, টেলিমেট্রি, আপলোড, বিজ্ঞাপন বা
ক্লাউড-প্রসেসিং বৈশিষ্ট্য। বর্তমান GPU মেট্রিক্স বাস্তবায়ন স্থানীয় Windows কর্মক্ষমতা ব্যবহার করে
কাউন্টার Linux এবং macOS এর জন্য সমতুল্য নেটিভ মেট্রিক্স প্রদানকারীর পরিকল্পনা করা হয়েছে।

ডায়াগনস্টিক সমস্যা সমাধানের জন্য, বিকাশকারীরা GUI শুরু করতে পারে
`--diagnostic-log <local-file.jsonl>`. লগ ইনপুট রাউটিং এবং ক্যামেরার অবস্থা স্থানীয়ভাবে রেকর্ড করে এবং হয়
স্বাভাবিক ব্যবহারের সময় অক্ষম।
