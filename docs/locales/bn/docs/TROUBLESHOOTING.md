# সমস্যা সমাধান

## Windows ডাউনলোড ব্লক করে

স্বাক্ষরবিহীন কমিউনিটি বিল্ড মাইক্রোসফট ডিফেন্ডার স্মার্টস্ক্রিনকে ট্রিগার করতে পারে। ডাউনলোড করা তুলনা করুন
একই GitHub রিলিজ থেকে `SHA256SUMS.txt` সহ ফাইলের SHA-256 হ্যাশ। স্বাক্ষরিত রিলিজ সনাক্ত
Windows ফাইল বৈশিষ্ট্যে তাদের প্রকাশক।

## পোর্টেবল বিল্ড শুরু হয় না

`MeshMill.exe` চালানোর আগে সম্পূর্ণ জিপটি বের করুন। `_internal` ডিরেক্টরিটি অবশ্যই পাশে থাকবে
উভয় এক্সিকিউটেবলের কাছে। জিপ ভিউয়ারের ভিতর থেকে এক্সিকিউটেবল চালাবেন না।

## একটি বড় STL একটি ওভারভিউ হিসাবে খোলে

আনুমানিক কাজের সেট সেটিংসে মেমরি বাজেট ছাড়িয়ে গেছে। ওভারভিউ মোড ইচ্ছাকৃতভাবে
শুধুমাত্র পঠনযোগ্য। মেশিনে পর্যাপ্ত মেমরি থাকলেই বাজেট বাড়ান, বা কমিয়ে দিন
সম্পাদনার জন্য এটি খোলার আগে জাল।

## একটি আদর্শ দৃশ্য সংরক্ষিত হয়নি

Ctrl-সংশোধিত ভিউ শর্টকাট টিপুন, তারপর **সংরক্ষণ করুন** চয়ন করুন বা নিশ্চিতকরণে এন্টার টিপুন
ডায়ালগ একটি ভিউ সংরক্ষণ করলে এর বিপরীতটিও আপডেট হয়। স্ট্যাটাস লাইন সেভ করা ভিউ রিপোর্ট করে।

## নেভিগেশন শর্টকাট সাড়া না

প্রথমে যেকোন মডেল ডায়ালগ বন্ধ করুন। সেটিংসে শর্টকাটগুলি পর্যালোচনা করুন বা রিসেট করুন যদি সেগুলি কাস্টমাইজ করা হয়৷ দ
ডিফল্ট ভিউ শর্টকাট ইনসার্ট, হোম, পেজ আপ, ডিলিট, এন্ড এবং পেজ ডাউন ব্যবহার করে।

## একটি স্থানীয় অভিযোজন ডায়গনিস্টিক লগ তৈরি করুন

ডায়াগনস্টিক লগিং ডিফল্টরূপে অক্ষম করা হয়৷ স্থানীয়ভাবে কীবোর্ড রাউটিং এবং ক্যামেরার অবস্থা রেকর্ড করতে:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

লগটিতে খোলা ফাইল পাথ থাকতে পারে। শেয়ার করার আগে পর্যালোচনা করুন এবং সংশোধন করুন। জাল জ্যামিতি নয়
লগে লেখা।

## একটি সমস্যা রিপোর্ট করুন

MeshMill সংস্করণ, Windows সংস্করণ, GPU মডেল, জাল ত্রিভুজ গণনা, সঠিক ক্রিয়া অন্তর্ভুক্ত করুন
ক্রম, এবং ইনস্টলার বা পোর্টেবল প্যাকেজ ব্যবহার করা হয়েছে কিনা। পুনরায় বিতরণযোগ্য নমুনা ব্যবহার করুন
যখন সম্ভব জাল। প্রথমে পর্যালোচনা না করে ব্যক্তিগত স্ক্যান বা ডায়াগনস্টিক লগ সংযুক্ত করবেন না।
