# অবদান

অবদানগুলিকে সমস্যা এবং অনুরোধের মাধ্যমে স্বাগত জানানো হয়।

## প্রকল্পের সুযোগ

MeshMill ডাউনস্ট্রিম সম্পাদনার জন্য ওভারসাইজ, ঘন বা কঠিন জাল ফাইলগুলিকে পরিচালনাযোগ্য করে তোলে এবং
উত্পাদন কর্মপ্রবাহ। অবদান জ্যামিতি পরিদর্শন, জাল এবং বিন্দু ঘনত্ব উন্নত করা উচিত
ব্যবস্থাপনা, অপ্টিমাইজেশান, নির্বাচন, ক্রপিং, ক্লিনআপ, বৈধতা, STL বিনিময়, কর্মক্ষমতা,
বা সেই অপারেশনগুলির সমন্বয়।

এই প্রকল্পে সাধারণ-উদ্দেশ্য মডেলিং, ভাস্কর্য, পেইন্টিং, অ্যানিমেশন, রেন্ডারিং,
দৃশ্য রচনা, উপকরণ, কারচুপি, বা অন্যান্য বিষয়বস্তু-সৃষ্টি সিস্টেম। প্রবর্তন যে প্রস্তাব
এই বৈশিষ্ট্যগুলি প্রকল্পের সুযোগের বাইরে।

নতুন বৈশিষ্ট্যগুলি অ্যাপ্লিকেশানটিকে ফোকাস করে রাখতে হবে, সরাসরি ওয়ার্কফ্লোগুলিকে সংরক্ষণ করতে হবে যা উৎসে পরিণত হয়৷
জ্যামিতিকে পরিচালনাযোগ্য মেশে পরিণত করুন এবং সমর্থনকারী নিয়ন্ত্রণগুলিকে সাধারণ সম্পাদনায় পরিণত করা এড়িয়ে চলুন
পরিবেশ

## স্থানীয়করণ

ইংরেজি UI সোর্স টেক্সট `locales/en-US.json` এ সংরক্ষিত আছে। লোকেল মেটাডেটা সংরক্ষিত হয়
`locales/manifest.json`. অনুবাদিত UI ক্যাটালগ একই স্থিতিশীল কী এবং ফাইলের নাম ব্যবহার করে
`<locale>.json`. অনূদিত ডকুমেন্টেশন এর অধীনে মিলে যাওয়া রুট ফাইলের নাম ব্যবহার করে
`docs/locales/<locale>/`.

অনুবাদ প্রাথমিকভাবে বাহ্যিক মেশিন-অনুবাদ পরিষেবার সাথে উত্পাদিত হয় এবং গ্রহণ করা হয়
স্বয়ংক্রিয় কাঠামোগত বৈধতা। সেই প্রক্রিয়া প্রাকৃতিক, প্রযুক্তিগতভাবে সুনির্দিষ্ট, বা গ্যারান্টি দিতে পারে না
প্রাসঙ্গিকভাবে সঠিক ভাষা। স্থানীয় ভাষাভাষীদের অনুদিত UI পর্যালোচনা এবং সংশোধন করতে উত্সাহিত করা হয়
পাঠ্য এবং ডকুমেন্টেশন। অনুবাদ সংশোধনের ক্যাটালগ কী, স্থানধারক সংরক্ষণ করা উচিত,
কমান্ড, লিঙ্ক, পরিমাপ, পণ্যের নাম এবং মার্কডাউন কাঠামো।

লেবেল, টুলটিপস, ডায়ালগ বা অন্যান্য ব্যবহারকারী-দৃশ্যমান পাঠ্য পরিবর্তন করার পরে, চালান:

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
```

উত্স পরিবর্তন এবং পুনরুত্পাদিত কীগুলি একসাথে পর্যালোচনা করুন৷

## জ্যামিতি এবং অ্যালগরিদম পরিবর্তন

অপ্টিমাইজেশান, ঘনত্ব বিশ্লেষণ, নির্বাচন, ক্রপিং, পরিবর্তন করার সময় বান্ডিল নমুনা জ্যামিতি ব্যবহার করুন
বড়-ফাইল হ্যান্ডলিং, বা ভিউপোর্ট তুলনা আচরণ। এতে ইচ্ছাকৃতভাবে অপ্রয়োজনীয় স্তর রয়েছে
এবং অসম ঘনত্ব, তাই একটি দরকারী ফলাফলের বিকৃতি লুকিয়ে না রেখে ব্যবস্থাপনার উন্নতি করা উচিত,
অর্থপূর্ণ সীমানা পরিত্যাগ করা, বা নীরবে জ্যামিতি অপসারণ যা অন্য অ্যালগরিদম সংরক্ষণ করে।

ইনপুট, অ্যালগরিদম, সেটিংস, ত্রিভুজ গণনা, মাত্রা, মাত্রা প্রবাহ, অতিবাহিত সময় রেকর্ড করুন,
এবং তুলনার জন্য প্রাসঙ্গিক স্ক্রিনশট। উভয় ছোট স্বাভাবিক-গিট ফিক্সচার পরীক্ষা করুন এবং, যখন
পরিবর্তন উদ্বেগ বড় বা স্তরযুক্ত জ্যামিতি, আসল Git LFS ফিক্সচার। একটি অ্যালগরিদম টিউন করবেন না
একা এই ফিক্সচারে. নির্দিষ্ট অপরিবর্তনীয় বা রিগ্রেশন সত্তার জন্য ছোট সিন্থেটিক কেস যোগ করুন
পরীক্ষিত

তুলনা চেকলিস্টের জন্য [অ্যালগরিদম পরীক্ষা এবং অবদান](docs/ALGORITHM_TESTING.md) দেখুন।

## উন্নয়ন সেটআপ

1. Windows-এ 64-বিট Python 3.12 ইনস্টল করুন।
2. একটি ভার্চুয়াল পরিবেশ তৈরি করুন এবং সক্রিয় করুন।
3. `requirements-dev.txt` ইনস্টল করুন।
4. GUI এর জন্য `python meshmill.py` বা CLI ব্যবহারের জন্য `python meshmill.py --help` চালান।
5. পরিবর্তন জমা দেওয়ার আগে `python -m py_compile meshmill.py` চালান।

ব্যক্তিগত মেশ, জেনারেট করা এক্সিকিউটেবল, ব্যক্তিগত তথ্য সম্বলিত স্ক্রিনশট এবং স্থানীয় রাখুন
কমিট থেকে ডিরেক্টরি তৈরি করুন। পুনরায় বিতরণযোগ্য পরীক্ষার জ্যামিতি `samples/` এর সাথে এর অন্তর্গত
উৎস, লাইসেন্স, মাত্রা, এবং প্রজন্মের পদ্ধতি নথিভুক্ত। নতুন উৎস ফাইল ব্যবহার করা উচিত
SPDX শনাক্তকারী `GPL-3.0-or-later`।

MeshMill অ্যাপ্লিকেশন সামগ্রীতে প্রতিটি ডকুমেন্টেশন স্ক্রিনশট ক্রপ করুন। অন্তর্ভুক্ত করবেন না
টাস্কবার, অসংলগ্ন উইন্ডো ক্রোম, বিজ্ঞপ্তি, অ্যাকাউন্টের বিশদ বিবরণ, ব্যক্তিগত পথ বা পটভূমি
ডেস্কটপ বিষয়বস্তু।
