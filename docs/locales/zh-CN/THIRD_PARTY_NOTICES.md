# 第三方软件

MeshMill 依赖于以下软件。这些组件保留自己的许可证并
版权声明。

|组件|版本 |许可证|
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | 3.12 Python 软件基础许可证 |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3 条款和捆绑许可许可证 |
| [快速简化](https://github.com/pyvista/fast-simplification) | 0.2.0 |麻省理工学院 |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3 条款 |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 |仅 LGPL-3.0、仅 GPL-2.0 或仅 GPL-3.0 |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 |仅 LGPL-3.0、仅 GPL-2.0 或仅 GPL-3.0 |
| [Py安装程序](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 或更高版本，带有引导加载程序例外 |

Windows 捆绑包在其 GPL-3.0 选项下分发 PySide6 和 Shiboken6，一致
具有 MeshMill 的 GPL-3.0 或更高版本的许可证。 NumPy 轮子包含额外的许可许可
组件；他们的通知包含在已安装的包元数据中，应保留
重新分发修改后的二进制包时。
