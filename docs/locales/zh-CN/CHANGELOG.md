# 变更日志

所有值得注意的版本更改都记录在此处。

## 0.1.0

- 将应用程序 GitHub 按钮连接到 MeshMill 存储库。
- 在“关于”对话框中添加了 GitHub 和请我喝杯咖啡链接。
- 新增本地STL加载、检查、选择、裁剪、删除、优化、导出。
- 添加了 Fast QEM、密度平衡、形状保持和拓扑保持优化。
- 添加了阴影、密度、线框和顶点显示模式。
- 添加了可取消的后台操作、缓存比较、撤消和重做。
- 添加了具有配对相反视图和可配置快捷键的标准视图校准。
- 添加了大网格内存预检和有界概览加载。
- 添加了 Windows 性能指标、便携式打包、安装程序打包和 CLI 操作。
- 添加了本地化目录和贡献者工具以供将来翻译。
