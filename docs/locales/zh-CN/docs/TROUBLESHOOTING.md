# 故障排除

## Windows 阻止下载

未签名的社区版本可以触发 Microsoft Defender SmartScreen。比较下载的
文件的 SHA-256 哈希值与来自同一 GitHub 版本的 `SHA256SUMS.txt`。签名发布标识
它们的发布者位于 Windows 文件属性中。

## 便携式构建无法启动

在运行 `MeshMill.exe` 之前提取完整的 ZIP。接下来必须保留 `_internal` 目录
到两个可执行文件。不要从 ZIP 查看器内部运行可执行文件。

## 大型 STL 打开作为概览

估计的工作集超出了“设置”中的内存预算。概览模式是故意的
只读。仅当机器有足够的可用内存时才增加预算，或者减少
在打开网格进行编辑之前。

## 未保存标准视图

按 Ctrl-修改视图快捷键，然后选择 **保存** 或在确认中按 Enter
对话框。保存一个视图也会更新其相反视图。状态行报告已保存的视图。

## 导航快捷方式没有响应

首先关闭任何模式对话框。如果自定义了快捷方式，请查看或重置“设置”中的快捷方式。的
默认视图快捷键使用 Insert、Home、Page Up、Delete、End 和 Page Down。

## 创建本地方向诊断日志

默认情况下禁用诊断日志记录。本地记录键盘路由和摄像头状态：

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

日志可能包含打开的文件路径。在分享之前查看并编辑它。网格几何形状不是
写入日志。

## 报告问题

包括MeshMill版本，Windows版本，GPU模型，网格三角形数，精确动作
顺序，以及是否使用安装程序或便携式软件包。使用可重新分发的示例
尽可能网格化。在未先查看的情况下，请勿附加私人扫描或诊断日志。
