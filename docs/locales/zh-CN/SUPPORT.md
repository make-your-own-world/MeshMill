# 支持自主开发

我是一名独立开发人员，喜欢使用开源软件解决实际问题。大多数
我的项目开始是因为我自己需要一个更好的工具，然后发展成对其他人有用的东西
人们。

我专注于构建可靠、可自托管且自动化友好的软件，以节省时间，
降低复杂性，并帮助现有系统更好地协同工作。构建有帮助的东西
人是我的动力。感觉就像我来这里是为了在这块岩石上度过我的时光。

这些项目需要时间、金钱和精力以及工作和日常生活。如果你发现了
我构建的有用的东西，您的支持有助于涵盖开发时间、测试硬件、托管、
以及正在进行的维护和改进工作。

支持可以采取多种形式。共享项目、报告错误、贡献修复或提供帮助
其他人追求自己的使命都会有所作为。有人对数学着迷，
化学、工程、艺术和无数其他领域需要一点帮助来完成工作
他们已经被驱使去做。

开箱视频和反应有其用武之地，但我们也需要人们让事情变得有价值
开放、值得回应的想法以及推动我们前进的发现。我希望我的工作有帮助
有人可以多做一点这样的事情，并且他们可以传递这种帮助。

感谢您使用我的项目并帮助为更多人创造、发现和创造空间
创建。
