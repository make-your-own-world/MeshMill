# 타사 소프트웨어

MeshMill는 다음 소프트웨어에 따라 다릅니다. 이러한 구성 요소는 자체 라이센스를 유지하며
저작권 고지.

| 구성요소 | 버전 | 라이센스 |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python 소프트웨어 재단 라이센스 |
| [넘파이](https://numpy.org/) | 2.5.3 | BSD-3 조항 및 번들 허용 라이센스 |
| [빠른 단순화](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3 조항 |
| [파이사이드6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0 전용, GPL-2.0 전용 또는 GPL-3.0 전용 |
| [시보켄6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0 전용, GPL-2.0 전용 또는 GPL-3.0 전용 |
| [Py설치 프로그램](https://pyinstaller.org/) | 6.22.3 | 부트로더 예외가 있는 GPL-2.0 이상 |

Windows 번들은 GPL-3.0 옵션에 따라 PySide6 및 Shiboken6을 배포합니다.
MeshMill의 GPL-3.0 이상 라이센스를 사용합니다. NumPy 휠에는 허용되는 추가 라이선스가 포함되어 있습니다.
구성 요소; 해당 통지는 설치된 패키지 메타데이터에 포함되며 유지되어야 합니다.
수정된 바이너리 번들을 재배포할 때.
