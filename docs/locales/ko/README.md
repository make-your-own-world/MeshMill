# MeshMill

![MeshMill 음영 처리된 뷰포트](../../images/meshmill-shaded.png)

MeshMill는 대형, 고밀도 또는 복잡한 메시(mesh) 형상을
관리하기 쉽게 만들어주는 데 특화된 데스크톱 애플리케이션입니다. 빠른 검사, 밀도 분석, 영역 선택, 자르기, 삭제,
그리고 계정 생성이나 형상 업로드 없이 제어 가능한 메시 축소 기능을 제공합니다.

GPU 가속 OpenGL 렌더링은 뷰포트 탐색, 하드웨어 피킹, 밀도 시각화 및 대화형 검사를 원활하게 유지합니다. 메시 축소는 현재 별도의 네이티브 CPU 작업자에서 실행되므로 긴 형상 계산이 인터페이스를 차단하지 않습니다.

MeshMill는 3D 스캐너, CAD 및 모델링 내보내기 파일, 재구성 파이프라인,
생성된 형상 및 기타 STL 소스에서 나온 메시를 처리합니다. 후속 편집기,
제조 도구 및 기타 메시 워크플로를 위한 형상 준비 작업을 수행합니다. 범용 모델링, 스컬프팅, 애니메이션,
재질 및 장면 생성 기능은 포함하지 않습니다.

## 다운로드

[GitHub 릴리스](../../releases)에서 다음 파일 중 하나를 다운로드하세요:

- `MeshMill-<version>-windows-x64-setup.exe`: 시작 메뉴 및 선택적
  바탕 화면 바로 가기를 포함하는 사용자별 설치 프로그램.
- `MeshMill-<version>-windows-x64-portable.zip`: 포터블 애플리케이션. 전체 아카이브의 압축을 풀고,
  `MeshMill.exe`를 실행하세요.

두 패키지 모두 애플리케이션 런타임을 포함하고 있습니다. 최종 사용자는 Python, Node.js 또는
종속성(dependencies)을 직접 설치하지 않습니다. 초기 릴리스는 x64 하드웨어에서 Windows 10 및 Windows 11을 지원합니다. Linux 및
macOS 패키지가 출시될 예정입니다. 제품 및 파일 형식은 Windows 전용이 아닙니다.

서명되지 않은 커뮤니티 빌드에서는 Windows SmartScreen 경고가 표시될 수 있습니다. 릴리스 체크섬은
각 릴리스 옆의 `SHA256SUMS.txt`에 나열되어 있습니다.

## 빠른 시작

1. STL를 엽니다.
2. Shaded(음영), Density(밀도), Wireframe(와이어프레임) 또는 Vertices(정점) 표시 모드에서 확인합니다.
3. 품질 수준, 알고리즘 및 목표 삼각형 개수를 선택합니다.
4. **Optimize(최적화)**를 선택하여 결과를 계산합니다.
5. 원본 메시와 최적화된 메시를 비교한 다음, **Apply(적용)**를 선택하여 작업을 확정합니다.
6. **Save current state(현재 상태 저장)**를 선택하거나 `Ctrl+S`를 누릅니다.

MeshMill는 파일이나 설정이 변경되었다는 이유만으로 최적화를 시작하지 않습니다.

## 기능

- Binary 및 ASCII STL 입력, Binary STL 출력
- Fast QEM 기반의 밀도 균형, 형상 보존 및 위상 보존형 축소(reduction)
- 음영(Shaded), 밀도, 와이어프레임 및 정점(vertex) 표시 모드
- 고정된 삼각형 개수 제한이 아닌 형상(geometry)에 기반한 자동 목표 설정
- 다중 영역 추가 선택 기능을 포함한 폴리곤 선택
- 선택한 영역만 자르기(crop), 삭제 또는 최적화
- 캐시된 원본, 이전 및 현재 메쉬(mesh) 비교
- 확정된 형상 변경 사항에 대한 실행 취소(Undo) 및 재실행(Redo)
- 치수 편차, 축소 비율 및 예상 출력 크기
- 밀리미터, 센티미터, 미터, 인치 및 피트 표시 단위
- CPU, 메모리, GPU 및 형상 작업 관련 지표
- Binary STL가 설정된 메모리 한도를 초과할 경우 제한된 개요(overview) 로딩
- GUI 및 명령줄(command-line) 애플리케이션
- 계정, 원격 측정(telemetry), 업로드 또는 클라우드 의존성 없이 로컬에서 처리

## 뷰(View) 제어

| 입력 | 동작 |
| --- | --- |
| 마우스 가운데 버튼 드래그 | 궤도 회전(Orbit) |
| Shift + 마우스 가운데 버튼 드래그 | 화면 이동(Pan) |
| 마우스 휠 | 포인터 방향으로 확대/축소 |
| Ctrl + 마우스 휠 | 시계 방향 또는 반시계 방향으로 회전 |
| 화살표 키 | 뷰 중심을 기준으로 궤도 회전 |
| Ctrl + 화살표 키 | 화면 이동(Pan) |
| Ctrl + Shift + 위/아래 화살표 | 확대/축소 |
| Ctrl + Shift + 왼쪽/오른쪽 | 롤 |
| `F1` / `F2` / `F3` / `F4` | 음영 처리/밀도/와이어프레임/정점 |
| 마우스 오른쪽 버튼 누르기 | 돋보기 |
| Shift + 왼쪽 클릭 | 눈금자 점 추가 또는 제거 |
| Ctrl + 왼쪽 드래그 | 선택 다각형 그리기 |
| `Ctrl+C` | 저장된 선택에 다각형 추가 |
| `Ctrl+X` | 선택 항목에 맞게 자르기 |
| `Ctrl+Space` | 선택 최적화 |
| `Delete` | 선택 항목 삭제 |
| `Escape` | 활성 선택 항목 또는 눈금자 지우기 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소/다시 실행 |
| `Ctrl+S` | 현재 메시 상태 저장 |

표준 보기 키는 6개 키 탐색 블록을 따릅니다.

| 열쇠 | 보기 | Ctrl + 키 |
| --- | --- | --- |
| `Insert` | 왼쪽 | 현재 방향을 왼쪽으로 설정 |
| `Home` | 전면 | 현재 방향을 전면으로 설정 |
| `Page Up` | 맞다 | 현재 방향을 오른쪽으로 설정 |
| `Delete` | 선택 항목이 없을 때 맨 위 | 현재 방향을 위쪽으로 설정 |
| `End` | 뒤로 | 현재 방향을 뒤로 |
| `Page Down` | 하단 | 현재 방향을 하단으로 설정 |

뷰를 저장하면 반대편 뷰도 업데이트됩니다. 왼쪽과 오른쪽, 앞과 뒤, 위쪽과 아래쪽
페어링 상태를 유지하세요. 확인 대화 상자에서는 **저장**이 기본 작업이므로 Enter 키를 누르면
오리엔테이션. Front는 Top 및 Bottom 뷰의 상단에 나타납니다.

바로가기는 설정에서 변경하거나 재설정할 수 있습니다.

## 선택 작업흐름

다각형을 그리려면 Ctrl 키를 누른 상태에서 왼쪽으로 드래그하세요. 모서리를 드래그하여 모양을 변경하고 가장자리를 마우스 왼쪽 버튼으로 클릭하여
점을 찍거나 모서리를 마우스 오른쪽 버튼으로 클릭하여 제거합니다. `Ctrl+C`로 더 많은 지역을 추가하세요. 카메라를 움직이면 숨겨집니다.
선택한 형상을 유지하면서 화면 공간 다각형.

활성 선택을 사용한 최적화는 해당 선택에만 영향을 미칩니다. 결과는 잠정적
**적용**이 선택될 때까지. **취소**는 임시 결과를 삭제하고 선택 항목을 유지합니다.
다른 구성을 시도할 수 있습니다. 자르기 및 삭제 작업은 실행 취소할 수 없는 일반적인 메시 편집이 됩니다.

## 큰 메쉬

바이너리 STL를 할당하기 전에 MeshMill는 예상 작업 메모리를 구성된 메모리와 비교합니다.
메모리 예산. 예산을 초과하는 파일은 제한된 읽기 전용 개요로 열립니다. 개요 보고서
전체 소스 삼각형 수는 있지만 전체가 아닌 샘플이기 때문에 편집 및 내보내기가 비활성화됩니다.
개체. 인덱싱된 확대/축소 종속 코어 외부 처리는 다음에서 계획됩니다.
[docs/OUT_OF_CORE.md](docs/OUT_OF_CORE.md).

## 명령줄

`MeshMillCLI.exe`는 두 릴리스 패키지에 모두 포함되어 있습니다.

```powershell
.\MeshMillCLI.exe "C:\path\mesh.stl" --preset balanced
.\MeshMillCLI.exe "C:\path\mesh.stl" --target 150000 --output "C:\path\mesh-reduced.stl"
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm density --target 150000
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm topology --overwrite
```

모든 옵션에 대해 `.\MeshMillCLI.exe --help`를 실행합니다. MeshMill는 입력 파일 덮어쓰기를 거부합니다.

## 샘플 기하학

두 가지 버전의 개발 샘플을 사용할 수 있습니다. 샘플은 다음과 같은 복합 메시입니다.
중복된 기하학과 다양한 밀도의 의도적인 레이어. 스캐너가 없는 사람들에게
알고리즘 비교, 밀도 검사, 지역 운영 실행을 위한 현실적인 장치
로드맵 기능을 개발합니다. MeshMill에는 스캔 입력이 필요하지 않습니다.

| 파일 | 삼각형 | 사이즈 | 배달 | |
| --- | ---: | ---: | --- | --- |
| [`sample-scan.stl`](../../../samples/sample-scan.stl) | 249,999 | 11.9MiB | 일반 힘내 | 빠른 평가, CI 및 컨트롤 학습 |
| [`original-scan.stl`](../../../samples/original-scan.stl) | 4,126,315 | 196.8MiB | Git LFS | 조밀한 소스 형상 및 대규모 메시 성능 테스트 |

모든 일반 클론에는 더 작은 샘플이 다운로드됩니다. 손대지 않은 원본은 선택 사항이며
Git LFS를 통해 관리되므로 일반 저장소 기록이 부풀려지지 않습니다. GitHub 데스크탑에는 다음이 포함됩니다.
Git LFS. 명령줄 사용자는 Git LFS를 설치하고 다음을 실행할 수 있습니다.

```powershell
git lfs pull --include="samples/original-scan.stl"
```

태그가 지정된 릴리스에서는 Git을 사용하지 않는 사람들을 위해 원본 STL를 직접 다운로드할 수도 있습니다.
출처, 차원 및 체크섬은 [`samples/README.md`](../../../samples/README.md)를 참조하세요.

알고리즘 기여자는 다음 내용도 읽어야 합니다.
[알고리즘 테스트 가이드](docs/ALGORITHM_TESTING.md) 축소를 비교하거나 변경하기 전에
행동.

## STL 장치

STL는 단위를 인코딩하지 않습니다. 모델 단위를 변경하면 크기 조정 없이 라벨과 측정값이 변경됩니다.
저장된 좌표 소스 형상을 설명하는 단위를 선택합니다.

## 개인 정보 보호

MeshMill는 로컬 파일을 읽고 씁니다. 여기에는 계정, 원격 측정, 업로드, 광고 또는 정보가 포함되어 있지 않습니다.
클라우드 처리 기능. 현재 GPU 메트릭 구현은 로컬 Windows 성능을 사용합니다.
카운터. Linux 및 macOS에 대해서도 동등한 기본 메트릭 공급자가 계획되어 있습니다.

진단 문제 해결을 위해 개발자는 다음을 사용하여 GUI를 시작할 수 있습니다.
`--diagnostic-log <local-file.jsonl>`. 로그는 입력 라우팅 및 카메라 상태를 로컬로 기록하고
정상적인 사용 중에는 비활성화됩니다.
