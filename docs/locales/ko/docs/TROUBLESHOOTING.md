# 문제 해결

## Windows가 다운로드를 차단합니다.

서명되지 않은 커뮤니티 빌드는 Microsoft Defender SmartScreen을 트리거할 수 있습니다. 다운로드한 것을 비교해보세요
동일한 GitHub 릴리스의 `SHA256SUMS.txt`가 포함된 파일의 SHA-256 해시. 서명된 릴리스는 다음을 식별합니다.
Windows 파일 속성의 게시자.

## 이식 가능한 빌드가 시작되지 않습니다

`MeshMill.exe`를 실행하기 전에 전체 ZIP을 추출하세요. `_internal` 디렉터리는 다음에 남아 있어야 합니다.
두 실행 파일 모두에. ZIP 뷰어 내부에서 실행 파일을 실행하지 마십시오.

## 대형 STL가 개요로 열립니다.

예상 작업 세트가 설정의 메모리 예산을 초과합니다. 개요 모드는 의도적으로
읽기 전용. 머신에 사용 가능한 메모리가 충분한 경우에만 예산을 늘리거나
편집을 위해 열기 전에 메시를 사용하세요.

## 표준 보기가 저장되지 않았습니다.

Ctrl 키를 누른 채 수정된 보기 단축키를 누른 다음 **저장**을 선택하거나 확인 메시지에서 Enter를 누르세요.
대화. 한 뷰를 저장하면 반대 뷰도 업데이트됩니다. 상태 표시줄은 저장된 보기를 보고합니다.

## 탐색 바로가기가 응답하지 않습니다.

먼저 모달 대화 상자를 닫습니다. 바로가기가 사용자 정의된 경우 설정에서 바로가기를 검토하거나 재설정하세요. 는
기본 보기 단축키는 삽입, 홈, 페이지 위로, 삭제, 종료 및 페이지 아래로를 사용합니다.

## 로컬 방향 진단 로그 생성

진단 로깅은 기본적으로 비활성화되어 있습니다. 키보드 라우팅 및 카메라 상태를 로컬로 기록하려면:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

로그에는 열린 파일 경로가 포함될 수 있습니다. 공유하기 전에 검토하고 수정하세요. 메쉬 기하학은 그렇지 않습니다.
로그에 기록됩니다.

## 문제 신고

MeshMill 버전, Windows 버전, GPU 모델, 메쉬 삼각형 개수, 정확한 동작 포함
순서 및 설치 프로그램 또는 휴대용 패키지가 사용되었는지 여부. 재배포 가능 샘플 사용
가능하다면 메쉬를 사용하세요. 먼저 검토하지 않은 채 비공개 스캔이나 진단 로그를 첨부하지 마십시오.
