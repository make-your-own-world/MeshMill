# 코어 외부 메시 아키텍처

MeshMill의 현재 대용량 파일 보호 기능은 전체 파일을 할당하기 전에 작업 메모리를 추정합니다.
메쉬. 구성된 예산을 초과하는 파일은 제한된 탐색 개요로 열릴 수 있습니다. 안
개요는 샘플링된 형상이며 시각적으로 식별되므로 다음과 같이 편집하거나 내보낼 수 없습니다.
완전한 소스였지만.

진정한 확대/축소 종속 세부 정보에는 지속적인 공간 색인이 필요합니다. 아래 디자인은 다음을 정의합니다.
다음 구현 단계.

## 인덱스 형식

각 소스 메시는 다음을 포함하는 버전이 지정된 `.meshmill-index` 디렉터리를 받습니다.

- `manifest.json`, 소스 크기, 수정 시간, 샘플링된 콘텐츠 해시, 경계,
  삼각형 개수, 인덱스 버전, 좌표 정밀도 및 레벨 설명;
- 옥트리 레벨 및 Morton 코드로 처리되는 공간 타일
- 점유된 모든 상위 타일에 대한 거친 디스플레이 메시
- 리프 타일의 전체 해상도 삼각형 레코드; 그리고
- 지역 운영 및 조립 중에 사용되는 경계 소유권 및 중복 메타데이터.

인덱스 생성은 제한된 블록에서 소스를 순차적으로 읽습니다. 임시 타일 실행을 작성하고
모든 필수 파일이 유효성 검사를 통과한 후 매니페스트를 원자적으로 게시합니다. 중단되었거나
오래된 인덱스는 매니페스트에서 감지되며 전체 인덱스를 열지 않고도 재개하거나 재구축할 수 있습니다.
메모리에 메쉬가 있습니다.

## 뷰포트 스트리밍

뷰포트는 카메라 절두체와 화면 공간 오류를 사용하여 타일을 선택합니다. 거친 상위 타일은
먼저 표시됩니다. 화면 밖에 있는 동안 카메라가 더 가까이 이동하면 보이는 하위 타일이 대체됩니다.
영향이 적은 타일은 거친 상태로 유지됩니다. RAM 및 VRAM에는 독립적인 예산이 있고 가장 최근에 사용된 제품이 있습니다.
캐시. 세부 사항을 해제하면 거친 전체 개체 표현이 해제되지 않습니다.

스케줄러는 대기 중, 읽기, 처리 중, 업로드 중, 상주, 실패 등의 타일 상태를 기록합니다.
취소되었습니다. 뷰포트는 상태별로 큐브의 색상을 지정하고 상태에 비례하여 각 큐브를 채울 수 있습니다.
진행. 취소하면 부분적인 결과가 제거되고 마지막 전체 표현이 활성 상태로 유지됩니다.

## 처리 및 용량

로컬 작업 단위는 타일에 해당 작업에 필요한 결정적 중첩이 추가된 것입니다. 동시성
현재 사용 가능한 RAM, 구성된 메모리 비율, 논리 프로세서 수 및
측정된 작업 단위 크기. GPU 업로드 및 표시에는 별도의 VRAM 예산이 있습니다. 보고된 병렬
용량은 대표 타일이 측정될 때까지의 추정치입니다.

작업에서는 모든 경계 요소에 대해 하나의 소유자를 유지합니다. 어셈블리는 공유 경계를 검증합니다.
중복을 제거하고, 개수와 경계를 확인하고, 사용된 정확한 매개변수를 기록합니다. 같은 작품
단위 및 결과 형식은 나중에 분산 합성 노드 전체에서 예약될 수 있습니다.

## 안전 규칙

- 전역 샘플은 전체 해상도 뷰포트 세부 사항이 아닌 개요로 레이블이 지정됩니다.
- 개요는 전체 소스 메시로 덮어쓰거나 내보낼 수 없습니다.
- 현재 예산을 초과하는 전체 로드 요청에는 명시적인 선택이 필요합니다.
- 인덱스 생성, 타일 처리, 조립은 취소 가능한 상태로 유지되며 이전 항목을 보존합니다.
  완전한 상태.
- 용량 값은 추정치이며 현재 엔진을 설명하는지 아니면 계획된 엔진을 설명하는지 식별합니다.
  병렬 타일 실행.
