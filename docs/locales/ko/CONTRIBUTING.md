# 기여

이슈 및 풀 요청을 통한 기여를 환영합니다.

## 프로젝트 범위

MeshMill는 다운스트림 편집을 위해 크기가 크거나 조밀하거나 어려운 메시 파일을 관리할 수 있도록 해줍니다.
생산 워크플로우. 기여를 통해 형상 검사, 메시 및 점 밀도가 향상되어야 합니다.
관리, 최적화, 선택, 자르기, 정리, 검증, STL 교환, 성능,
또는 그러한 운영의 조정.

이 프로젝트에는 범용 모델링, 조각, 페인팅, 애니메이션, 렌더링,
장면 구성, 재료, 리깅 또는 기타 콘텐츠 제작 시스템. 소개하는 제안
이러한 기능은 프로젝트 범위를 벗어납니다.

새로운 기능은 애플리케이션의 초점을 유지하고 소스를 전환하는 직접적인 워크플로를 유지해야 합니다.
지오메트리를 관리 가능한 메시로 변환하고 지원 컨트롤을 일반 편집으로 전환하지 마세요.
환경.

## 현지화

영어 UI 소스 텍스트는 `locales/en-US.json`에 저장됩니다. 로캘 메타데이터는 다음 위치에 저장됩니다.
`locales/manifest.json`. 번역된 UI 카탈로그는 동일한 안정적인 키와 파일 이름을 사용합니다.
`<locale>.json`. 번역된 문서는 다음과 일치하는 루트 파일 이름을 사용합니다.
`docs/locales/<locale>/`.

레이블, 도구 설명, 대화 상자 또는 기타 사용자에게 표시되는 텍스트를 변경한 후 다음을 실행합니다.

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
```

소스 변경 사항과 재생성된 키를 함께 검토하세요.

## 기하학 및 알고리즘 변경

최적화, 밀도 분석, 선택, 자르기 등을 변경할 때 번들 샘플 형상을 사용하십시오.
대용량 파일 처리 또는 뷰포트 비교 동작. 의도적으로 중복 레이어를 포함합니다.
밀도가 불균등하므로 유용한 결과는 왜곡을 숨기지 않고 관리성을 향상시켜야 합니다.
의미 있는 경계를 삭제하거나 다른 알고리즘이 유지하는 형상을 자동으로 제거합니다.

입력, 알고리즘, 설정, 삼각형 개수, 차원, 차원 드리프트, 경과 시간,
그리고 비교를 위한 관련 스크린샷. 더 작은 Normal-Git Fixture를 테스트하고,
변경 사항은 원래 Git LFS 고정 장치인 크거나 계층화된 형상에 관한 것입니다. 알고리즘을 조정하지 마십시오
이 고정 장치에만. 특정 불변 또는 회귀에 대한 작은 합성 사례를 추가합니다.
테스트되었습니다.

비교 체크리스트는 [알고리즘 테스트 및 기여](docs/ALGORITHM_TESTING.md)를 참조하세요.

## 개발 설정

1. Windows에 64비트 Python 3.12를 설치합니다.
2. 가상 환경을 생성하고 활성화합니다.
3. `requirements-dev.txt`를 설치합니다.
4. GUI의 경우 `python meshmill.py`를 실행하고 CLI 사용의 경우 `python meshmill.py --help`를 실행하세요.
5. 변경 사항을 제출하기 전에 `python -m py_compile meshmill.py`를 실행하세요.

비공개 메시, 생성된 실행 파일, 개인 정보가 포함된 스크린샷 및 로컬을 유지합니다.
커밋으로 디렉터리를 구축합니다. 재배포 가능 테스트 형상은 `samples/`에 속합니다.
소스, 라이센스, 크기 및 생성 방법이 문서화되어 있습니다. 새 소스 파일은 다음을 사용해야 합니다.
SPDX 식별자 `GPL-3.0-or-later`.

모든 문서 스크린샷을 MeshMill 애플리케이션 콘텐츠로 자릅니다. 다음을 포함하지 마세요.
작업 표시줄, 관련 없는 창 크롬, 알림, 계정 세부정보, 개인 경로 또는 배경
데스크톱 콘텐츠.
