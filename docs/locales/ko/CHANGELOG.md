# 변경 내역

모든 주목할만한 릴리스 변경 사항이 여기에 문서화되어 있습니다.

## 0.1.0

- 애플리케이션 GitHub 버튼을 MeshMill 저장소에 연결했습니다.
- 정보 대화 상자에 GitHub 및 Buy Me a Coffee 링크를 추가했습니다.
- 로컬 STL 로드, 검사, 선택, 자르기, 삭제, 최적화 및 내보내기가 추가되었습니다.
- Fast QEM, 밀도 균형, 형태 보존 및 토폴로지 보존 최적화가 추가되었습니다.
- 음영 처리, 밀도, 와이어프레임 및 정점 표시 모드가 추가되었습니다.
- 취소 가능한 백그라운드 작업, 캐시된 비교, 실행 취소 및 다시 실행이 추가되었습니다.
- 쌍을 이루는 반대쪽 보기와 구성 가능한 바로 가기가 포함된 표준 보기 보정이 추가되었습니다.
- 대형 메시 메모리 프리플라이트 및 제한된 개요 로딩이 추가되었습니다.
- Windows 성능 지표, 휴대용 패키징, 설치 프로그램 패키징 및 CLI 작업이 추가되었습니다.
- 향후 번역을 위해 현지화 카탈로그 및 기여자 도구가 추가되었습니다.
