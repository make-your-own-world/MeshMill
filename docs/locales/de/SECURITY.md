# Sicherheitspolitik

## Unterstützte Versionen

Sicherheitskorrekturen werden auf die neueste veröffentlichte MeshMill-Version angewendet.

## Eine Schwachstelle melden

Verwenden Sie die private Schwachstellenberichtsfunktion von GitHub, wenn sie für das Repository aktiviert ist. Nicht
Dazu gehören private Mesh-Dateien, Anmeldeinformationen, Diagnoseprotokolle oder persönliche Informationen, sofern dies nicht der Fall ist
zur Reproduktion des Sachverhalts verpflichtet sind und deren Offenlegung ausdrücklich genehmigt wurde.

Geben Sie die betroffene Version, das Betriebssystem, die Reproduktionsschritte und die erwarteten Auswirkungen an. Öffentlich
Probleme eignen sich für gewöhnliche Fehler, die keine Daten offenlegen oder eine Sicherheitsgrenze schaffen
Misserfolg.
