# Software von Drittanbietern

MeshMill hängt von der folgenden Software ab. Diese Komponenten behalten ihre eigenen Lizenzen und
Urheberrechtshinweise.

| Komponente | Version | Lizenz |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Software Foundation-Lizenz |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-Klausel und gebündelte Freizügigkeitslizenzen |
| [schnelle Vereinfachung](https://github.com/pyvista/fast-simplification) | 0,2,0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Klausel |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0-only, GPL-2.0-only oder GPL-3.0-only |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0-only, GPL-2.0-only oder GPL-3.0-only |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 oder höher mit einer Bootloader-Ausnahme |

Das Windows-Bundle vertreibt PySide6 und Shiboken6 konsistent unter ihrer GPL-3.0-Option
mit der GPL-3.0-oder höher-Lizenz von MeshMill. NumPy-Räder enthalten zusätzliche freizügige Lizenzen
Komponenten; Ihre Hinweise sind in den Metadaten des installierten Pakets enthalten und sollten beibehalten werden
bei der Weiterverteilung eines geänderten Binärpakets.
