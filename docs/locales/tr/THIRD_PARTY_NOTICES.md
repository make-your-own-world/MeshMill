# Üçüncü taraf yazılım

MeshMill aşağıdaki yazılıma bağlıdır. Bu bileşenler kendi lisanslarını korur ve
telif hakkı bildirimleri.

| Bileşen | Sürüm | Lisans |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Yazılım Temel Lisansı |
| [SayıPy](https://numpy.org/) | 2.5.3 | BSD-3-Madde ve paket halindeki izin verilen lisanslar |
| [hızlı basitleştirme](https://github.com/pyvista/fast-simplification) | 0.2.0 | MİT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Madde |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | Yalnızca LGPL-3.0, yalnızca GPL-2.0 veya yalnızca GPL-3.0 |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | Yalnızca LGPL-3.0, yalnızca GPL-2.0 veya yalnızca GPL-3.0 |
| [PyYükleyici](https://pyinstaller.org/) | 6.22.3 | Önyükleyici istisnasıyla GPL-2.0 veya üzeri |

Windows paketi, PySide6 ve Shiboken6'yı tutarlı bir şekilde GPL-3.0 seçeneği altında dağıtır
MeshMill'nin GPL-3.0 veya üzeri lisansı ile. NumPy tekerlekleri ek izin verilen lisanslar içerir
bileşenler; bildirimleri yüklü paket meta verilerine dahil edilmiştir ve saklanmalıdır
değiştirilmiş bir ikili paketi yeniden dağıtırken.
