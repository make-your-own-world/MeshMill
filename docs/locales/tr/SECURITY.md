# Güvenlik politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri en son yayınlanan MeshMill sürümüne uygulanmıştır.

## Bir güvenlik açığını bildirme

Depo için etkinleştirildiğinde GitHub'nin özel güvenlik açığı raporlama özelliğini kullanın. Yapamaz
özel ağ dosyalarını, kimlik bilgilerini, teşhis günlüklerini veya kişisel bilgileri içermediği sürece
konunun çoğaltılması gerekli olup, bunların açıklanması açıkça onaylanmıştır.

Etkilenen sürümü, işletim sistemini, çoğaltma adımlarını ve beklenen etkiyi ekleyin. halka açık
sorunlar, verileri açığa çıkarmayan veya bir güvenlik sınırı oluşturmayan sıradan hatalar için uygundur
başarısızlık.
