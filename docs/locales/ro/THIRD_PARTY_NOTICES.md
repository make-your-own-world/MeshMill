# Software de la terți

MeshMill depinde de următorul software. Aceste componente își păstrează propriile licențe și
notificări privind drepturile de autor.

| Componenta | Versiune | Licență |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Licență Software Foundation |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-Clauza și licențe permisive grupate |
| [simplificare rapidă](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Clauza |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | Numai LGPL-3.0, numai GPL-2.0 sau numai GPL-3.0 |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | Numai LGPL-3.0, numai GPL-2.0 sau numai GPL-3.0 |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 sau o versiune ulterioară cu o excepție de încărcător de pornire |

Pachetul Windows distribuie PySide6 și Shiboken6 sub opțiunea lor GPL-3.0, consecvent
cu licența MeshMill GPL-3.0 sau o versiune ulterioară. Roțile NumPy conțin licențe suplimentare permisive
componente; notificările lor sunt incluse în metadatele pachetului instalat și ar trebui păstrate
la redistribuirea unui pachet binar modificat.
