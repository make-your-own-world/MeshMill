# Politica de securitate

## Versiuni acceptate

Remedierile de securitate sunt aplicate celei mai recente ediții MeshMill publicate.

## Raportarea unei vulnerabilități

Utilizați caracteristica privată de raportare a vulnerabilităților a GitHub atunci când este activată pentru depozit. Nu
includ fișiere mesh private, acreditări, jurnale de diagnosticare sau informații personale, cu excepția cazului în care acestea sunt
necesare pentru a reproduce problema și dezvăluirea lor a fost aprobată în mod explicit.

Includeți versiunea afectată, sistemul de operare, pașii de reproducere și impactul așteptat. Public
problemele sunt adecvate pentru erorile obișnuite care nu expun date sau nu creează o limită de securitate
eșec.
