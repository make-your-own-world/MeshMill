# Содействие

Вклады приветствуются через вопросы и запросы на включение.

## Объем проекта

MeshMill позволяет управлять большими, плотными или сложными файлами сеток для последующего редактирования и
производственные рабочие процессы. Вклад должен улучшить контроль геометрии, плотность сетки и точек.
управление, оптимизация, выбор, обрезка, очистка, проверка, обмен STL, производительность,
или координация этих операций.

Проект не включает в себя универсальное моделирование, лепку, рисование, анимацию, рендеринг,
композиция сцены, материалы, оснащение или другие системы создания контента. Предложения, которые знакомят
эти функции выходят за рамки проекта.

Новые функции должны сохранять целенаправленность приложения, сохранять прямые рабочие процессы, которые превращаются в исходный код.
геометрию в управляемые сетки и избегайте превращения вспомогательных элементов управления в общее редактирование.
окружающая среда.

## Локализация

Исходный текст пользовательского интерфейса на английском языке хранится в `locales/en-US.json`. Метаданные локали хранятся в
`locales/manifest.json`. Переведенные каталоги пользовательского интерфейса используют одни и те же стабильные ключи и имя файла.
`<locale>.json`. В переведенной документации используется соответствующее корневое имя файла в разделе
`docs/locales/<locale>/`.

После изменения меток, всплывающих подсказок, диалоговых окон или другого видимого пользователю текста запустите:

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
```

Вместе просмотрите изменения исходного кода и восстановленные ключи.

## Изменения геометрии и алгоритма

Используйте встроенную геометрию образца при изменении оптимизации, анализа плотности, отбора, обрезки и т. д.
обработка больших файлов или поведение сравнения областей просмотра. Он намеренно содержит избыточные слои.
и неравномерная плотность, поэтому полезный результат должен улучшить управляемость, не скрывая искажений,
отбрасывание значимых границ или молчаливое удаление геометрии, которую сохраняет другой алгоритм.

Запишите вводимые данные, алгоритм, настройки, количество треугольников, размеры, смещение размеров, прошедшее время.
и соответствующие скриншоты для сравнения. Протестируйте как меньшую приспособленность нормального Git, так и, когда
Изменения касаются крупной или многослойной геометрии оригинального приспособления Git LFS. Не настраивайте алгоритм
только к этому прибору. Добавьте небольшие синтетические случаи для конкретного инварианта или регрессии.
протестировано.

Контрольный список для сравнения см. в разделе [Тестирование и вклад алгоритма](docs/ALGORITHM_TESTING.md).

## Настройка разработки

1. Установите 64-битную версию Python 3.12 на Windows.
2. Создайте и активируйте виртуальную среду.
3. Установите `requirements-dev.txt`.
4. Запустите `python meshmill.py` для графического интерфейса или `python meshmill.py --help` для использования CLI.
5. Запустите `python -m py_compile meshmill.py` перед отправкой изменения.

Сохраняйте частные сетки, сгенерированные исполняемые файлы, снимки экрана, содержащие личную информацию, и локальные файлы.
создавать каталоги из коммитов. Распространяемая тестовая геометрия принадлежит `samples/` с ее
документированы источник, лицензия, размеры и метод создания. Новые исходные файлы должны использовать
Идентификатор SPDX `GPL-3.0-or-later`.

Обрежьте каждый снимок экрана документации до содержимого приложения MeshMill. Не включайте
панель задач, несвязанный хром окна, уведомления, данные учетной записи, личные пути или фон
содержимое рабочего стола.
