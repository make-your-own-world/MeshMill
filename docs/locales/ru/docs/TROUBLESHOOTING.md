# Устранение неполадок

## Windows блокирует загрузку

Неподписанные сборки сообщества могут активировать функцию SmartScreen Microsoft Defender. Сравните скачанные
хэш SHA-256 файла с `SHA256SUMS.txt` из той же версии GitHub. Подписанные релизы идентифицируют
их издателя в свойствах файла Windows.

## Портативная сборка не запускается

Извлеките полный ZIP-архив перед запуском `MeshMill.exe`. Каталог `_internal` должен оставаться следующим.
для обоих исполняемых файлов. Не запускайте исполняемый файл из программы просмотра ZIP.

## Большой STL открывается в виде обзора.

Предполагаемый рабочий набор превышает бюджет памяти, указанный в Настройках. Режим обзора намеренно
только для чтения. Увеличивайте бюджет только тогда, когда на машине достаточно доступной памяти, или уменьшите
сетку, прежде чем открыть ее для редактирования.

## Стандартный вид не сохранился

Нажмите ярлык измененного представления, удерживая клавишу Ctrl, затем выберите **Сохранить** или нажмите Enter в подтверждении.
диалог. Сохранение одного представления также обновляет противоположное. В строке состояния сообщается о сохраненном представлении.

## Навигационные ярлыки не реагируют

Сначала закройте любое модальное диалоговое окно. Просмотрите или сбросьте ярлыки в настройках, если они были настроены.
Ярлыки просмотра по умолчанию используют «Вставка», «Домой», «Страница вверх», «Удалить», «Конец» и «Страница вниз».

## Создайте журнал диагностики локальной ориентации.

Ведение журнала диагностики отключено по умолчанию. Чтобы локально записать маршрутизацию клавиатуры и состояние камеры:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

Журнал может содержать путь к открытому файлу. Просмотрите и отредактируйте его, прежде чем поделиться. Геометрия сетки не
записано в журнал.

## Сообщить о проблеме

Включает версию MeshMill, версию Windows, модель GPU, количество треугольников сетки, точное действие.
последовательность действий и то, использовался ли установочный или переносной пакет. Используйте распространяемый образец
сетку, когда это возможно. Не прикрепляйте частные сканирования или журналы диагностики, не просмотрев их предварительно.
