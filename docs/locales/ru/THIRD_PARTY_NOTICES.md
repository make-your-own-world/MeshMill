# Стороннее программное обеспечение

MeshMill зависит от следующего программного обеспечения. Эти компоненты сохраняют свои собственные лицензии и
уведомления об авторских правах.

| Компонент | Версия | Лицензия |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Лицензия Software Foundation |
| [NumPy](https://numpy.org/) | 2.5.3 | Пункт BSD-3 и комплексные разрешительные лицензии |
| [быстрое упрощение](https://github.com/pyvista/fast-simplification) | 0.2.0 | Массачусетский технологический институт |
| [ВТК](https://vtk.org/) | 9.7.1 | Пункт BSD-3 |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | Только LGPL-3.0, только GPL-2.0 или только GPL-3.0 |
| [Сибокен6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | Только LGPL-3.0, только GPL-2.0 или только GPL-3.0 |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 или более поздней версии с исключением загрузчика |

Пакет Windows распространяет PySide6 и Shiboken6 под лицензией GPL-3.0, что соответствует
с лицензией MeshMill GPL-3.0 или более поздней версии. Колеса NumPy содержат дополнительные лицензированные
компоненты; их уведомления включены в метаданные установленного пакета и должны быть сохранены.
при перераспределении модифицированного двоичного пакета.
