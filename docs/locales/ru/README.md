MeshMill — это специализированное настольное приложение для работы с крупногабаритными, высокодетализированными или сложными полигональными моделями (мешами),
делающее их обработку удобной. Оно обеспечивает быстрый осмотр, анализ плотности сетки, выделение областей, обрезку, удаление,
а также контролируемое упрощение сетки без необходимости создания учетной записи или загрузки геометрии в облако.

Рендеринг OpenGL с графическим ускорением обеспечивает навигацию по области просмотра, выбор оборудования, визуализацию плотности и (GPU)
и интерактивный контроль оперативно реагирует. Уменьшение сетки в настоящее время выполняется в отдельных рабочих процессах ЦП. (CPU)
хранение длинных геометрических вычислений вдали от интерфейса.

MeshMill работает с сетками, полученными с помощью 3D-сканеров, экспортированными из CAD-систем и программ для моделирования,
а также с геометрией, созданной алгоритмически или полученной из других источников. Приложение подготавливает геометрию для дальнейшей обработки в других редакторах, (STL)
производственном ПО и других рабочих процессах. Моделирование общего назначения, скульптинг, анимация,
работа с материалами и создание сцен выходят за рамки его функциональности.

## Краткое руководство

1. Откройте STL.
2. Просмотрите модель в режиме отображения Shaded (с затенением), Density (плотность), Wireframe (каркас) или Vertices (вершины).
3. Выберите уровень качества, алгоритм и целевое количество треугольников.
4. Нажмите **Optimize** (Оптимизировать) для выполнения расчета.
5. Сравните исходную и оптимизированную сетки, затем нажмите **Apply** (Применить), чтобы зафиксировать результат.
6. Выберите **Save current state** (Сохранить текущее состояние) или нажмите `Ctrl+S`.

MeshMill не запускает оптимизацию автоматически только из-за изменения файла или настроек.

## Возможности

- Ввод данных в форматах STL (бинарный и ASCII), вывод в формате STL (бинарный)
- Упрощение (редукция) сетки Fast QEM с сохранением плотности, формы и топологии
- Окно просмотра OpenGL с графическим ускорением, выбор оборудования и визуализация плотности (GPU)
- Встроенные средства обработки фоновой геометрии для уменьшения сетки
- Режимы отображения: с затенением, карта плотности, каркас (wireframe) и вершины
- Автоматическое определение целевых параметров на основе геометрии, а не фиксированного ограничения количества треугольников
- Выбор полигонов с возможностью аддитивного выделения нескольких областей
- Обрезка, удаление или оптимизация только выбранной области
- Сравнение исходной, предыдущей и текущей версий сетки (с использованием кэширования)
- Отмена и повтор выполненных изменений геометрии
- Отслеживание отклонения размеров, процента упрощения и оценочного размера выходного файла
- Единицы измерения: миллиметры, сантиметры, метры, дюймы и футы
- Метрики: данные CPU, использование памяти, данные GPU и показатели геометрической сложности
- Загрузка ограниченного представления (обзора) при превышении бинарным файлом STL заданного лимита памяти
- Приложения с графическим интерфейсом (GUI) и интерфейсом командной строки
- Локальная обработка без необходимости создания учетной записи, передачи телеметрии, загрузки данных на сервер или использования облачных сервисов

## Проверьте геометрию перед ее уменьшением

Затененный дисплей обеспечивает четкое представление поверхности и силуэта. Это полезно для сравнения
сохранение формы перед применением прохода оптимизации.

![Затененное окно просмотра MeshMill, показывающее связанный образец сетки](../../images/meshmill-shaded.png)

Отображение вершин отображает фактическое распределение точек. Плотные области сканирования, редкие области и
видны резкие изменения выборки без изменения геометрии. Расширенная панель показателей
отслеживает активность процессора, памяти, графического процессора и обработки геометрии во время работы с сеткой. (GPU) (CPU)

![Отображение вершин MeshMill с расширенными показателями производительности](../../images/meshmill-vertices.png)

В режиме «Каркас» непосредственно отображается структура треугольника. Это помогает выявить ненужную плотность,
неправильная триангуляция и области, где упрощение может удалить существенную геометрию.

![Каркасное отображение MeshMill, показывающее изменение плотности треугольников](../../images/meshmill-wireframe.png)

## Анализ плотности сетки

Экран «Плотность» отображает относительную локальную плотность по всей модели. Редкие регионы остаются прохладными, пока
все более плотные области перемещаются через более яркие цвета, что делает неравномерность выборки заметной с первого взгляда.

![Отображение плотности MeshMill, показывающее относительную плотность сетки](../../images/meshmill-density.png)

Плотность остается доступной при оценке предварительной оптимизации. Панель инструментов сообщает о
алгоритм, цель, результирующее количество треугольников и вершин, процент уменьшения, размеры и
предполагаемый выходной размер до применения прохода.

![Отображение плотности MeshMill, показывающее предварительную оптимизацию](../../images/meshmill-density-overview.png)

Удерживайте правую кнопку мыши, чтобы осмотреть область с помощью круговой лупы. Увеличенный вид
остается в центре указателя и отображает локальную плотность без изменения положения основной камеры.

![Отображение плотности MeshMill с помощью лупы видового экрана](../../images/meshmill-density-zoom.png)

## Рабочий процесс выбора

Удерживайте Ctrl и перетащите левую кнопку мыши, чтобы нарисовать многоугольник. Перетащите углы, чтобы изменить его форму, щелкните левой кнопкой мыши по краю, чтобы добавить
точку или щелкните правой кнопкой мыши край, чтобы удалить его. Добавьте больше регионов с помощью `Ctrl+C`. Перемещение камеры скрывает
многоугольник экранного пространства, сохраняя при этом выбранную геометрию.

Оптимизация с активным выбором влияет только на этот выбор. Результат остается предварительным
пока не будет выбрано **Применить**. **Отмена** отменяет предварительный результат и сохраняет выбор.
можно попробовать другую конфигурацию. Операции обрезки и удаления становятся обычными отменяемыми изменениями сетки.

На панели выбора отображается совокупное количество выбранных вершин, треугольников, доля сетки, приблизительная оценка.
размер и габариты. Его действия обрезают, добавляют, оптимизируют, удаляют, отступают или очищают сохраненные
выделение без скрытия окружающей геометрии.

![MeshMill показывает сохраненное региональное выделение и его геометрическую статистику](../../images/meshmill-crop-selection.png)

## Большие сетки

Прежде чем выделить двоичный файл STL, MeshMill сравнивает свою предполагаемую рабочую память с настроенной.
бюджет памяти. Файл над бюджетом открывается как ограниченный обзор, доступный только для чтения. Обзорные отчеты
полное исходное количество треугольников, но отключает редактирование и экспорт, поскольку это образец, а не полный
объект. Индексированная внеядерная обработка, зависящая от масштабирования, планируется в
[docs/OUT_OF_CORE.md](docs/OUT_OF_CORE.md).

## Командная строка

`MeshMillCLI.exe` включен в оба пакета выпуска:

```powershell
.\MeshMillCLI.exe "C:\path\mesh.stl" --preset balanced
.\MeshMillCLI.exe "C:\path\mesh.stl" --target 150000 --output "C:\path\mesh-reduced.stl"
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm density --target 150000
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm topology --overwrite
```

Запустите `.\MeshMillCLI.exe --help` для всех вариантов. MeshMill отказывается перезаписывать входной файл.

## Образец геометрии

Доступны две версии образца разработки. Образец представляет собой композитную сетку с
преднамеренные слои избыточной геометрии и различной плотности. Это дает людям без сканера
реалистичное приспособление для сравнения алгоритмов, проверки плотности, выполнения региональных операций,
и разработка функций дорожной карты. MeshMill не требует сканированного ввода.

| Файл | Треугольники | Размер | Доставка | Лучшее для |
| --- | ---: | ---: | --- | --- |
| [`sample-scan.stl`](../../../samples/sample-scan.stl) | 249 999 | 11,9 МБ | Обычный Git | Быстрая оценка, CI и изучение элементов управления | (249,999)
| [`original-scan.stl`](../../../samples/original-scan.stl) | 4 126 315 | 196,8 МБ | Git ОФС | Тестирование плотной геометрии источника и производительности на крупной сетке | (4,126,315) (Git LFS)

Меньший образец загружается вместе с каждым обычным клоном. Нетронутый оригинал не является обязательным и
управляется через Git LFS, чтобы он не раздувал обычную историю репозитория. GitHub Desktop включает в себя
Git LFS. Пользователи командной строки могут установить Git LFS и запустить:

```powershell
git lfs pull --include="samples/original-scan.stl"
```

В выпусках с тегами также публикуется оригинальный STL для прямой загрузки для людей, которые не используют Git.
См. [`samples/README.md`](../../../samples/README.md) для получения информации о происхождении, размерах и контрольных суммах.

Разработчики алгоритмов также должны прочитать
[руководство по тестированию алгоритма](docs/ALGORITHM_TESTING.md) перед сравнением или изменением сокращения
поведение.

## Блоки STL

STL не кодирует единицу измерения. Изменение единиц измерения модели меняет метки и размеры без масштабирования.
сохраненные координаты. Выберите единицу измерения, описывающую исходную геометрию.

## Конфиденциальность

MeshMill читает и записывает локальные файлы. Он не содержит учетных записей, телеметрии, загрузки, рекламы или
функция облачной обработки. Текущая реализация метрик GPU использует локальную производительность Windows.
счетчики. Эквивалентные собственные поставщики метрик запланированы для Linux и macOS.

Для диагностики неполадок разработчики могут запустить графический интерфейс с помощью
`--diagnostic-log <local-file.jsonl>`. В журнале локально фиксируется входная маршрутизация и состояние камеры.
отключен при обычном использовании.
