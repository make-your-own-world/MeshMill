# Политика безопасности

## Поддерживаемые версии

Исправления безопасности применены к последней опубликованной версии MeshMill.

## Сообщить об уязвимости

Используйте функцию частных отчетов об уязвимостях GitHub, если она включена для репозитория. Не
включать личные файлы сетки, учетные данные, журналы диагностики или личную информацию, если они не
необходимы для воспроизведения проблемы, и их раскрытие было явно одобрено.

Укажите затронутую версию, операционную систему, этапы воспроизведения и ожидаемое влияние. Общественный
проблемы подходят для обычных ошибок, которые не раскрывают данные и не создают границы безопасности.
