# Registro delle modifiche

Tutte le modifiche importanti alla versione sono documentate qui.

## 0.1.0

- Connesso il pulsante GitHub dell'applicazione al repository MeshMill.
- Aggiunti i collegamenti GitHub e Comprami un caffè alla finestra di dialogo Informazioni.
- Aggiunto caricamento, ispezione, selezione, ritaglio, eliminazione, ottimizzazione ed esportazione locale STL.
- Aggiunto Fast QEM, ottimizzazione con bilanciamento della densità, preservazione della forma e preservazione della topologia.
- Aggiunte modalità di visualizzazione ombreggiata, densità, wireframe e vertice.
- Aggiunte operazioni in background annullabili, confronti memorizzati nella cache, annullamento e ripetizione.
- Aggiunta calibrazione della vista standard con viste opposte accoppiate e scorciatoie configurabili.
- Aggiunto il preflight della memoria a mesh di grandi dimensioni e il caricamento della panoramica limitata.
- Aggiunti parametri prestazionali Windows, pacchetto portatile, pacchetto di installazione e funzionamento CLI.
- Aggiunti cataloghi di localizzazione e strumenti di collaborazione per traduzioni future.
