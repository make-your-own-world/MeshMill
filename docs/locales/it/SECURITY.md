# Politica di sicurezza

## Versioni supportate

Le correzioni di sicurezza vengono applicate all'ultima versione pubblicata MeshMill.

## Segnalazione di una vulnerabilità

Utilizza la funzione di segnalazione delle vulnerabilità private di GitHub quando è abilitata per il repository. Non farlo
includere file mesh privati, credenziali, registri diagnostici o informazioni personali a meno che non lo siano
tenuti a riprodurre il problema e la loro divulgazione è stata esplicitamente approvata.

Includere la versione interessata, il sistema operativo, i passaggi di riproduzione e l'impatto previsto. Pubblico
I problemi sono appropriati per i bug ordinari che non espongono dati o creano un limite di sicurezza
fallimento.
