# Усунення несправностей

## Windows блокує завантаження

Непідписані збірки спільноти можуть активувати Microsoft Defender SmartScreen. Порівняйте завантажене
хеш SHA-256 файлу з `SHA256SUMS.txt` з того самого випуску GitHub. Підписані релізи ідентифікують
їх видавець у властивостях файлу Windows.

## Портативна збірка не запускається

Розпакуйте повний ZIP перед запуском `MeshMill.exe`. Наступним має залишатися каталог `_internal`
до обох виконуваних файлів. Не запускайте виконуваний файл із засобу перегляду ZIP.

## Великий STL відкривається як огляд

Приблизний робочий набір перевищує бюджет пам’яті в налаштуваннях. Режим огляду навмисно
тільки для читання. Збільшуйте бюджет лише тоді, коли машина має достатньо доступної пам’яті, або зменшуйте
сітку, перш ніж відкривати її для редагування.

## Стандартний вигляд не збережено

Натисніть ярлик перегляду, зміненого Ctrl, а потім виберіть **Зберегти** або натисніть Enter у підтвердженні
діалог. Збереження одного перегляду також оновлює його протилежне. Рядок стану повідомляє про збережений вигляд.

## Швидкі клавіші навігації не реагують

Спочатку закрийте будь-яке модальне діалогове вікно. Перегляньте або скиньте ярлики в налаштуваннях, якщо вони були налаштовані. The
ярлики перегляду за замовчуванням використовують Insert, Home, Page Up, Delete, End і Page Down.

## Створіть журнал діагностики локальної орієнтації

За замовчуванням журнал діагностики вимкнено. Щоб записати маршрутизацію клавіатури та стан камери локально:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

Журнал може містити відкритий шлях до файлу. Перегляньте та відредагуйте його, перш ніж ділитися. Геометрія сітки – ні
записано в журналі.

## Повідомте про проблему

Включити версію MeshMill, версію Windows, модель GPU, кількість сітчастих трикутників, точну дію
послідовність і чи використовувався інсталятор чи портативний пакет. Використовуйте зразок для повторного розповсюдження
сітка, коли це можливо. Не долучайте приватні скани або журнали діагностики, не переглянувши їх попередньо.
