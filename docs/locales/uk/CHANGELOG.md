# Журнал змін

Тут задокументовано всі помітні зміни випуску.

## 0.1.0

- Додано локальне завантаження, перевірку, вибір, обрізання, видалення, оптимізацію та експорт STL.
- Додано Fast QEM, оптимізацію зі збалансованою щільністю, збереженням форми та збереженням топології.
- Додано режими відображення затінених, щільності, каркасних і вершинних.
- Додано скасовані фонові операції, кешовані порівняння, скасування та повторення.
- Додано калібрування стандартного виду з парними протилежними видами та настроюваними ярликами.
- Додано попередню перевірку пам’яті великої сітки та обмежене завантаження огляду.
- Додано показники продуктивності Windows, портативне пакування, пакування інсталятора та роботу CLI.
- Додано каталоги локалізації та інструменти співавторів для майбутніх перекладів.
