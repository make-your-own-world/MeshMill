# Політика безпеки

## Підтримувані версії

Виправлення безпеки застосовано до останнього опублікованого випуску MeshMill.

## Повідомлення про вразливість

Використовуйте функцію приватного звітування про вразливості GitHub, якщо її ввімкнено для сховища. не треба
включати приватні файли сітки, облікові дані, діагностичні журнали або особисту інформацію, якщо вони не є
необхідні для відтворення проблеми, і їх розкриття було чітко схвалено.

Включіть уражену версію, операційну систему, етапи відтворення та очікуваний вплив. Громадський
Проблеми підходять для звичайних помилок, які не розкривають дані та не створюють кордон безпеки
невдача.
