# Стороннє програмне забезпечення

MeshMill залежить від наступного програмного забезпечення. Ці компоненти зберігають власні ліцензії та
повідомлення про авторські права.

| Компонент | Версія | Ліцензія |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Ліцензія Software Foundation |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-Clause та пакетні дозвільні ліцензії |
| [швидке спрощення](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Clause |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | Лише LGPL-3.0, Лише GPL-2.0 або Лише GPL-3.0 |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | Лише LGPL-3.0, Лише GPL-2.0 або Лише GPL-3.0 |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 або новішої версії з винятком завантажувача |

Пакет Windows розповсюджує PySide6 і Shiboken6 відповідно до GPL-3.0, відповідно
з ліцензією MeshMill GPL-3.0 або пізнішою. Колеса NumPy містять додаткові дозвільні ліцензії
компоненти; їхні сповіщення включені в метадані встановленого пакета та повинні зберігатися
під час перерозподілу модифікованого бінарного комплекту.
