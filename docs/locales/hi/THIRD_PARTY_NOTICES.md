# तृतीय-पक्ष सॉफ़्टवेयर

MeshMill निम्नलिखित सॉफ्टवेयर पर निर्भर करता है। ये घटक अपने स्वयं के लाइसेंस बनाए रखते हैं और
कॉपीराइट नोटिस.

| घटक | संस्करण | लाइसेंस |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python सॉफ्टवेयर फाउंडेशन लाइसेंस |
| [NumPy](https://numpy.org/) | 2.5.3 | बीएसडी-3-खंड और बंडल अनुज्ञेय लाइसेंस |
| [तेज़-सरलीकरण](https://github.com/pyvista/fast-simplification) | 0.2.0 | एमआईटी |
| [वीटीके](https://vtk.org/) | 9.7.1 | बीएसडी-3-खंड |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | एलजीपीएल-3.0-केवल, जीपीएल-2.0-केवल, या जीपीएल-3.0-केवल |
| [शिबोकेन6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | एलजीपीएल-3.0-केवल, जीपीएल-2.0-केवल, या जीपीएल-3.0-केवल |
| [पाइइंस्टॉलर](https://pyinstaller.org/) | 6.22.3 | बूटलोडर अपवाद के साथ जीपीएल-2.0-या-बाद का संस्करण |

Windows बंडल लगातार उनके GPL-3.0 विकल्प के तहत PySide6 और Shiboken6 वितरित करता है
MeshMill के GPL-3.0-या-बाद के लाइसेंस के साथ। NumPy व्हील्स में अतिरिक्त रूप से लाइसेंस प्राप्त होते हैं
घटक; उनके नोटिस स्थापित पैकेज मेटाडेटा में शामिल हैं और उन्हें बनाए रखा जाना चाहिए
संशोधित बाइनरी बंडल को पुनर्वितरित करते समय।
