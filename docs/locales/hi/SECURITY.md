# सुरक्षा नीति

## समर्थित संस्करण

नवीनतम प्रकाशित MeshMill रिलीज़ पर सुरक्षा सुधार लागू किए गए हैं।

## किसी भेद्यता की रिपोर्ट करना

रिपॉजिटरी के लिए सक्षम होने पर GitHub की निजी भेद्यता रिपोर्टिंग सुविधा का उपयोग करें। ऐसा न करें
निजी मेश फ़ाइलें, क्रेडेंशियल, डायग्नोस्टिक लॉग या व्यक्तिगत जानकारी शामिल करें जब तक कि वे न हों
मुद्दे को पुन: प्रस्तुत करना आवश्यक है और उनके प्रकटीकरण को स्पष्ट रूप से अनुमोदित किया गया है।

प्रभावित संस्करण, ऑपरेटिंग सिस्टम, पुनरुत्पादन चरण और अपेक्षित प्रभाव शामिल करें। सार्वजनिक
मुद्दे सामान्य बग के लिए उपयुक्त हैं जो डेटा को उजागर नहीं करते हैं या सुरक्षा सीमा नहीं बनाते हैं
विफलता.
