# Ослобађање MeshMill

Цјевовод стабилног издања гради Виндовс артефакте на Виндовс тркачима које хостује ГитХуб. Одвојено (GitHub) (Windows) (Windows)
ручни ток посла гради непотписани Линук к86-64 и мацОС Интел/Аппле силиконски преглед на изворном (Linux) (macOS)
Тркачи које хостује ГитХуб. Крајњи корисници не инсталирају Питхон, Ноде.јс или зависности. (Python) (Node.js) (GitHub)

Пре прављења, освежите и потврдите изворне каталоге локализације:

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
python tools/release_privacy_check.py
```

## Пре првог јавног објављивања

1. Завршите и потврдите планиране преводе апликација и документације.
2. Прегледајте ГПЛ и обавештења трећих страна.
3. Тестирајте инсталацију, покретање, учитавање STL, оптимизацију, извоз и деинсталацију на чистом
   Windows налог или виртуелна машина.
4. Покрените ЦИ против `samples/sample-scan.stl`. Прегледајте сваки снимак екрана са документацијом и исеците га
   трака задатака, хром прозора који није део MeshMill, обавештења, приватне путање, налог
   детаљи и неповезани садржај десктопа пре објављивања.
5. Конфигуришите локалног Гит аутора у спремишту са GitHub адресом налога без одговора пре
   прво урезивање. Потврдите то са `git config --local --get user.email`.
6. Конфигуришите опционалне тајне потписивања Аутхентицоде:
   - `WINDOWS_CERTIFICATE_BASE64`: ПФКС сертификат кодиран Басе64.
   - `WINDOWS_CERTIFICATE_PASSWORD`: ПФКС лозинка.

Без сертификата за потписивање, генерисане датотеке и даље раде, али Windows СмартСцреен може да прикаже
упозорење непризнатог издавача. Немојте описивати непотписане верзије као потписане или поуздане.

## Оригинално скенирање и Git LFS

`samples/original-scan.stl` се прати преко Git LFS јер премашује нормалних 100 миБ GitHub
ограничење датотеке. Пре првог урезивања, проверите:

```powershell
git check-attr filter -- samples/original-scan.stl
git lfs pointer --file samples/original-scan.stl
```

Филтер мора бити `lfs`, а ИД објекта показивача мора одговарати `samples/SHA256SUMS.txt`. Ослобађање
ток посла проверава ЛФС садржај и објављује оригинални STL као засебно издање. ЦИ користи
мањи узорак нормалног Гита и не преузима ЛФС објекат.

## Тестирајте верзију издања без објављивања

Отворите **Радње**, изаберите **Ослободи**, изаберите **Покрени радни ток** и унесите нумеричку верзију као што је
`0.1.0`. Ручно покретање отпрема артефакте тока посла за тестирање, али не ствара јавни GitHub
Релеасе.

## Објавите издање

Из чисте, прегледане гране `main`:

```powershell
git tag -a v0.1.0 -m "MeshMill 0.1.0"
git push origin v0.1.0
```

Ознака покреће ток посла за издавање. То:

1. инсталира закачене зависности изградње;
2. генерише одговарајуће метаподатке верзије Windows;
3. гради самосталне ГУИ и ЦЛИ извршне датотеке;
4. потписује извршне датотеке када су конфигурисане тајне за потписивање;
5. прави инсталатер Инно Сетуп по кориснику;
6. потписује инсталатер када је конфигурисан;
7. креира преносиви ЗИП и СХА-256 датотеку контролне суме;
8. отпрема артефакте тока посла;
9. креира GitHub Релеасе за гурнуту ознаку.

Проверите инсталациони програм и преносиву архиву на чистом систему Windows пре него што објавите издање.
Држите извор који одговара сваком дистрибуираном бинарном фајлу доступан под истом ознаком издања.
Потврдите да дугме GitHub указује на коначну УРЛ адресу јавног спремишта пре него што означите прву
ослобађање.

## Направите прегледе за Линук и мацОС (Linux) (macOS)

Отворите **Радње**, изаберите **Израђене верзије за преглед платформе** и изаберите **Покрени ток посла**. Унесите преглед
верзија као што је `0.2.0-превиев.1`.

Оставите **Објави јавно ГитХуб претходно издање** искључено за прво покретање. Ток посла се гради и тестира: (GitHub)

- Линук к86-64 на Убунту 22.04; (Linux)
- мацОС к86-64 на Интел тркачу; (macOS)
- мацОС арм64 на Аппле силиконском тркачу. (macOS)

Преузмите артефакте тока посла и прегледајте њихове контролне суме и евиденције. Поново покрените ток посла са
објављивање је омогућено само након што сваки посао изградње прође. Објављени прегледи мацОС-а су ад хоц потписани, (macOS)
није оверено код Аппле-а. Опишите их као верзије за преглед и повезујте тестере са њима
`доцс/ПЛАТФОРМ_ТЕСТИНГ.мд` и образац за издавање **Тест прегледа платформе**.
