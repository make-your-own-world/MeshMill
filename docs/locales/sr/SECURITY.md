# Безбедносна политика

## Подржане верзије

Безбедносне исправке се примењују на најновије издање MeshMill.

## Пријављивање рањивости

Користите приватну функцију извештавања о рањивости GitHub када је омогућена за спремиште. немој
укључују приватне месх датотеке, акредитиве, дијагностичке евиденције или личне податке осим ако нису
потребно да се репродукује питање и њихово обелодањивање је изричито одобрено.

Укључите верзију на коју се односи, оперативни систем, кораке репродукције и очекивани утицај. Јавно
проблеми су прикладни за обичне грешке које не откривају податке нити стварају безбедносну границу
неуспех.
