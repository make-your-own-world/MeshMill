# تغییرات

همه تغییرات قابل توجه انتشار در اینجا مستند شده است.

## 0.1.0

- اضافه شدن بارگذاری محلی STL، بازرسی، انتخاب، برش، حذف، بهینه سازی و صادرات.
- Fast QEM اضافه شد، بهینه سازی با تراکم متعادل، حفظ شکل و حفظ توپولوژی.
- حالت های نمایش سایه دار، چگالی، قاب سیمی و راس اضافه شده است.
- اضافه شدن عملیات پس‌زمینه قابل لغو، مقایسه‌های ذخیره‌شده در حافظه پنهان، لغو و انجام مجدد.
- اضافه شدن کالیبراسیون نمای استاندارد با نماهای مخالف جفت شده و میانبرهای قابل تنظیم.
- اضافه شدن پیش از پرواز حافظه مشبک بزرگ و بارگیری نمای کلی محدود.
- معیارهای عملکرد Windows، بسته بندی قابل حمل، بسته بندی نصب کننده و عملیات CLI اضافه شد.
- کاتالوگ های محلی سازی و ابزار مشارکت کننده برای ترجمه های آینده اضافه شده است.
