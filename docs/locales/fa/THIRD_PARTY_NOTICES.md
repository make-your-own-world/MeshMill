# نرم افزار شخص ثالث

MeshMill به نرم افزار زیر بستگی دارد. این قطعات مجوزهای خود را حفظ می کنند و
اعلامیه های حق چاپ

| جزء | نسخه | مجوز |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | مجوز بنیاد نرم افزار Python |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-Clause و مجوزهای مجاز همراه |
| [ساده سازی سریع](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Clause |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0-only، GPL-2.0-only، یا GPL-3.0-only |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0-only، GPL-2.0-only، یا GPL-3.0-only |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0-یا جدیدتر با استثنا بوت لودر |

بسته نرم افزاری Windows PySide6 و Shiboken6 را تحت گزینه GPL-3.0 خود توزیع می کند، سازگار
با مجوز GPL-3.0 یا جدیدتر MeshMill. چرخ های NumPy حاوی مجوزهای اضافی هستند
اجزاء؛ اعلامیه های آنها در فراداده بسته نصب شده گنجانده شده است و باید حفظ شود
هنگام توزیع مجدد یک بسته باینری اصلاح شده.
