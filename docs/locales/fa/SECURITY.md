## گزارش یک آسیب پذیری

از ویژگی گزارش آسیب‌پذیری خصوصی GitHub زمانی که برای مخزن فعال است، استفاده کنید. نکن
شامل فایل‌های مش خصوصی، اعتبارنامه‌ها، گزارش‌های تشخیصی یا اطلاعات شخصی باشد، مگر اینکه چنین باشد
مورد نیاز برای بازتولید موضوع و افشای آنها به صراحت تایید شده است.

شامل نسخه تحت تأثیر، سیستم عامل، مراحل بازتولید و تأثیر مورد انتظار باشد. عمومی
