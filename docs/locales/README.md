# Localized documentation

The root Markdown files are the authoritative English documents. Translated files belong in
`docs/locales/<locale>/` with the same filenames and heading structure. The document set and
supported locales are defined in `manifest.json`.

Translations are initially produced with external machine-translation services and automated
structural validation. Native speakers should review and correct wording, terminology, technical
meaning, and cultural context. Corrections should preserve links, code, placeholders, measurements,
product names, catalog keys, and document structure.
