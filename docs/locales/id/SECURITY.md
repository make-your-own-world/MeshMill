# Kebijakan keamanan

## Versi yang didukung

Perbaikan keamanan diterapkan pada rilis terbaru MeshMill.

## Melaporkan kerentanan

Gunakan fitur pelaporan kerentanan pribadi GitHub ketika diaktifkan untuk repositori. Tidak
menyertakan file mesh pribadi, kredensial, log diagnostik, atau informasi pribadi kecuali jika memang demikian
diharuskan untuk mereproduksi masalah tersebut dan pengungkapannya telah disetujui secara eksplisit.

Sertakan versi yang terpengaruh, sistem operasi, langkah-langkah reproduksi, dan dampak yang diharapkan. Publik
masalah ini sesuai untuk bug biasa yang tidak mengekspos data atau membuat batas keamanan
kegagalan.
