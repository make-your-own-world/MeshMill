# ซอฟต์แวร์บุคคลที่สาม

MeshMill ขึ้นอยู่กับซอฟต์แวร์ต่อไปนี้ ส่วนประกอบเหล่านี้ยังคงมีใบอนุญาตของตนเองและ
ประกาศเกี่ยวกับลิขสิทธิ์

| ส่วนประกอบ | เวอร์ชั่น | ใบอนุญาต |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | ใบอนุญาตมูลนิธิซอฟต์แวร์ Python |
| [NumPy](https://numpy.org/) | 2.5.3 | BSD-3-Clause และสิทธิ์การใช้งานแบบรวม |
| [ลดความซับซ้อนอย่างรวดเร็ว](https://github.com/pyvista/fast-simplification) | 0.2.0 | เอ็มไอที |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-ข้อ |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0-only, GPL-2.0-only, or GPL-3.0-only |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0-only, GPL-2.0-only, or GPL-3.0-only |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 หรือใหม่กว่าพร้อมข้อยกเว้น bootloader |

ชุด Windows จัดจำหน่าย PySide6 และ Shiboken6 ภายใต้ตัวเลือก GPL-3.0 ซึ่งสอดคล้องกัน
ด้วยใบอนุญาต GPL-3.0 หรือใหม่กว่าของ MeshMill ล้อ NumPy มีใบอนุญาตเพิ่มเติมที่ได้รับอนุญาต
ส่วนประกอบ; ประกาศจะรวมอยู่ในข้อมูลเมตาของแพ็คเกจที่ติดตั้งและควรเก็บไว้
เมื่อแจกจ่ายบันเดิลไบนารีที่แก้ไขแล้วอีกครั้ง
