# นโยบายความปลอดภัย

## รุ่นที่รองรับ

การแก้ไขด้านความปลอดภัยจะนำไปใช้กับ MeshMill ที่เผยแพร่ล่าสุด

## การรายงานจุดอ่อน

ใช้คุณลักษณะการรายงานช่องโหว่ส่วนตัวของ GitHub เมื่อเปิดใช้งานสำหรับพื้นที่เก็บข้อมูล อย่า
รวมถึงไฟล์ mesh ส่วนตัว ข้อมูลประจำตัว บันทึกการวินิจฉัย หรือข้อมูลส่วนบุคคล เว้นแต่จะเป็นอย่างนั้น
จำเป็นต้องทำซ้ำปัญหาและการเปิดเผยข้อมูลได้รับการอนุมัติอย่างชัดเจน

รวมถึงเวอร์ชันที่ได้รับผลกระทบ ระบบปฏิบัติการ ขั้นตอนการทำซ้ำ และผลกระทบที่คาดหวัง สาธารณะ
ปัญหามีความเหมาะสมสำหรับข้อบกพร่องทั่วไปที่ไม่เปิดเผยข้อมูลหรือสร้างขอบเขตความปลอดภัย
ความล้มเหลว
