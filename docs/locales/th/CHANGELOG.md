# บันทึกการเปลี่ยนแปลง

การเปลี่ยนแปลงการเปิดตัวที่โดดเด่นทั้งหมดได้รับการบันทึกไว้ที่นี่

## 0.1.0

- เชื่อมต่อปุ่ม GitHub ของแอปพลิเคชันกับที่เก็บ MeshMill
- เพิ่มลิงก์ GitHub และ Buy Me a Coffee ไปยังกล่องโต้ตอบเกี่ยวกับ
- เพิ่มการโหลด การตรวจสอบ การเลือก การครอบตัด การลบ การเพิ่มประสิทธิภาพ และการส่งออก STL ในเครื่อง
- เพิ่ม Fast QEM การปรับสมดุลความหนาแน่น การรักษารูปร่าง และการเพิ่มประสิทธิภาพการรักษาโทโพโลยี
- เพิ่มโหมดการแสดงผลแบบแรเงา ความหนาแน่น โครงร่าง และจุดยอด
- เพิ่มการดำเนินการในพื้นหลังที่ยกเลิกได้ การเปรียบเทียบแคช เลิกทำ และทำซ้ำ
- เพิ่มการปรับเทียบมุมมองมาตรฐานด้วยมุมมองที่ตรงกันข้ามและทางลัดที่กำหนดค่าได้
- เพิ่ม preflight หน่วยความจำแบบตาข่ายขนาดใหญ่และการโหลดภาพรวมแบบมีขอบเขต
- เพิ่มตัวชี้วัดประสิทธิภาพ Windows บรรจุภัณฑ์แบบพกพา แพ็คเกจการติดตั้ง และการทำงานของ CLI
- เพิ่มแคตตาล็อกการแปลและเครื่องมือสำหรับการแปลในอนาคต
