# สถาปัตยกรรมตาข่ายนอกคอร์

การป้องกันไฟล์ขนาดใหญ่ในปัจจุบันของ MeshMill จะประเมินหน่วยความจำที่ใช้งานก่อนที่จะจัดสรรให้เสร็จสมบูรณ์
ตาข่าย ไฟล์ที่เกินงบประมาณที่กำหนดค่าไว้สามารถเปิดเป็นภาพรวมการนำทางแบบมีขอบเขตได้ อ
ภาพรวมเป็นรูปทรงเรขาคณิตตัวอย่าง มีการระบุอย่างชัดเจน และไม่สามารถแก้ไขหรือส่งออกเป็นได้
แม้จะเป็นแหล่งที่สมบูรณ์ก็ตาม

รายละเอียดที่ต้องอาศัยการซูมที่แท้จริงต้องใช้ดัชนีเชิงพื้นที่ถาวร การออกแบบด้านล่างนี้กำหนดว่า
ระยะการดำเนินการต่อไป

## รูปแบบดัชนี

แต่ละ Source Mesh จะได้รับไดเร็กทอรี `.meshmill-index` ที่มีเวอร์ชันประกอบด้วย:

- `manifest.json` พร้อมขนาดแหล่งที่มา เวลาในการแก้ไข แฮชเนื้อหาตัวอย่าง ขอบเขต
  การนับสามเหลี่ยม เวอร์ชันของดัชนี ความแม่นยำของพิกัด และคำอธิบายระดับ
- กระเบื้องเชิงพื้นที่กำหนดโดยระดับออคทรีและรหัสมอร์ตัน
- ตาข่ายแสดงผลแบบหยาบสำหรับไทล์หลักทุกอันที่ถูกครอบครอง
- บันทึกรูปสามเหลี่ยมความละเอียดสูงสุดในแผ่นใบไม้ และ
- ความเป็นเจ้าของขอบเขตและข้อมูลเมตาที่ทับซ้อนกันซึ่งใช้ระหว่างการดำเนินงานและการประกอบระดับภูมิภาค

การสร้างดัชนีจะอ่านแหล่งที่มาตามลำดับในบล็อกที่มีขอบเขต มันเขียนการรันไทล์ชั่วคราวและ
เผยแพร่รายการแบบอะตอมมิกหลังจากทุกไฟล์ที่จำเป็นผ่านการตรวจสอบความถูกต้อง ถูกขัดจังหวะหรือ
ตรวจพบดัชนีเก่าจากไฟล์ Manifest และสามารถดำเนินการต่อหรือสร้างใหม่ได้โดยไม่ต้องเปิดดัชนีทั้งหมด
ตาข่ายในหน่วยความจำ

## การสตรีมวิวพอร์ต

วิวพอร์ตเลือกไทล์โดยใช้ข้อผิดพลาดของกล้องและข้อผิดพลาดของพื้นที่หน้าจอ กระเบื้องพาเรนต์หยาบได้แก่
แสดงก่อน ไทล์ย่อยที่มองเห็นได้จะเข้ามาแทนที่เมื่อกล้องเคลื่อนเข้ามาใกล้ยิ่งขึ้น ขณะอยู่นอกหน้าจอ และ
กระเบื้องที่มีแรงกระแทกต่ำยังคงหยาบ RAM และ VRAM มีงบประมาณที่เป็นอิสระและใช้งานน้อยที่สุด
แคช รายละเอียดการเผยแพร่จะไม่เผยแพร่การแสดงวัตถุทั้งหมดแบบหยาบ

ตัวกำหนดเวลาจะบันทึกสถานะไทล์เหล่านี้: เข้าคิว, กำลังอ่าน, กำลังประมวลผล, กำลังอัปโหลด, มีถิ่นที่อยู่, ล้มเหลว,
และยกเลิก วิวพอร์ตสามารถระบายสีลูกบาศก์ตามสถานะ และเติมแต่ละลูกบาศก์ตามสัดส่วนของมัน
ความคืบหน้า การยกเลิกจะลบผลลัพธ์บางส่วนออกและปล่อยให้การแสดงที่สมบูรณ์ครั้งล่าสุดใช้งานได้

## การประมวลผลและความจุ

หน่วยงานเฉพาะที่คือไทล์บวกกับการทับซ้อนที่กำหนดซึ่งจำเป็นสำหรับการดำเนินงาน เห็นพ้องต้องกัน
ถูกต่อยอดโดย RAM ที่พร้อมใช้งานในปัจจุบัน เปอร์เซ็นต์หน่วยความจำที่กำหนดค่า จำนวนตัวประมวลผลแบบลอจิคัล และ
ขนาดหน่วยงานที่วัดได้ การอัปโหลดและการแสดงผล GPU มีงบประมาณ VRAM แยกต่างหาก รายงานขนานกัน
ความจุเป็นการประมาณการจนกว่าจะมีการวัดกระเบื้องตัวแทน

การดำเนินการจะรักษาเจ้าของไว้หนึ่งรายสำหรับทุกๆ องค์ประกอบขอบเขต สภาตรวจสอบขอบเขตที่ใช้ร่วมกัน
ลบรายการที่ซ้ำกัน ตรวจสอบจำนวนและขอบเขต และบันทึกพารามิเตอร์ที่ใช้ งานเดียวกัน
หน่วยและรูปแบบผลลัพธ์สามารถกำหนดเวลาได้ในภายหลังข้ามโหนดการสังเคราะห์แบบกระจาย

## กฎความปลอดภัย

- ตัวอย่างส่วนกลางจะมีป้ายกำกับว่าเป็นภาพรวม ไม่ใช่รายละเอียดวิวพอร์ตที่มีความละเอียดเต็ม
- ภาพรวมไม่สามารถเขียนทับหรือส่งออกเป็นตาข่ายต้นทางที่สมบูรณ์ได้
- คำขอโหลดเต็มที่เกินงบประมาณปัจจุบันจำเป็นต้องมีตัวเลือกที่ชัดเจน
- การสร้างดัชนี การประมวลผลไทล์ และการประกอบยังคงสามารถยกเลิกได้และรักษาไว้ก่อนหน้านี้
  สถานะที่สมบูรณ์
- ค่ากำลังการผลิตเป็นการประมาณการและระบุว่าค่าดังกล่าวอธิบายถึงกลไกปัจจุบันหรือที่วางแผนไว้
  การดำเนินการไทล์คู่ขนาน
