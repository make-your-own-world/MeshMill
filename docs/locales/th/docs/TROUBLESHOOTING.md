# การแก้ไขปัญหา

## Windows บล็อกการดาวน์โหลด

การสร้างชุมชนที่ไม่ได้ลงนามสามารถทริกเกอร์ Microsoft Defender SmartScreen ได้ เปรียบเทียบที่ดาวน์โหลดมา
แฮช SHA-256 ของไฟล์ที่มี `SHA256SUMS.txt` จาก GitHub Release เดียวกัน ระบุการเผยแพร่ที่ลงนามแล้ว
ผู้เผยแพร่ในคุณสมบัติไฟล์ Windows

## บิลด์แบบพกพาไม่เริ่มทำงาน

แยก ZIP ให้สมบูรณ์ก่อนที่จะรัน `MeshMill.exe` ไดเร็กทอรี `_internal` จะต้องยังคงอยู่ถัดไป
ไปยังไฟล์ปฏิบัติการทั้งสอง อย่าเรียกใช้ไฟล์ปฏิบัติการจากภายในโปรแกรมดู ZIP

## STL ขนาดใหญ่จะเปิดขึ้นเป็นภาพรวม

ชุดการทำงานโดยประมาณเกินงบประมาณหน่วยความจำในการตั้งค่า โหมดภาพรวมมีเจตนา
อ่านอย่างเดียว เพิ่มงบประมาณเฉพาะเมื่อเครื่องมีหน่วยความจำเพียงพอหรือลด
mesh ก่อนที่จะเปิดเพื่อแก้ไข

## มุมมองมาตรฐานไม่ได้รับการบันทึก

กดทางลัดมุมมองที่แก้ไขด้วย Ctrl จากนั้นเลือก **บันทึก** หรือกด Enter ในการยืนยัน
กล่องโต้ตอบ การบันทึกมุมมองเดียวยังอัปเดตสิ่งที่ตรงกันข้ามด้วย บรรทัดสถานะรายงานมุมมองที่บันทึกไว้

## ทางลัดการนำทางไม่ตอบสนอง

ปิดกล่องโต้ตอบโมดอลใดๆ ก่อน ตรวจสอบหรือรีเซ็ตทางลัดในการตั้งค่าหากได้รับการปรับแต่ง ที่
ปุ่มลัดมุมมองเริ่มต้นใช้การแทรก หน้าแรก เลื่อนหน้าขึ้น ลบ สิ้นสุด และเลื่อนหน้าลง

## สร้างบันทึกการวินิจฉัยการวางแนวเฉพาะที่

การบันทึกเพื่อการวินิจฉัยถูกปิดใช้งานตามค่าเริ่มต้น หากต้องการบันทึกการกำหนดเส้นทางแป้นพิมพ์และสถานะกล้องในเครื่อง:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

บันทึกอาจมีเส้นทางของไฟล์ที่เปิดอยู่ ตรวจสอบและแก้ไขก่อนแชร์ เรขาคณิตของตาข่ายไม่ได้
เขียนลงในบันทึก

## รายงานปัญหา

รวมเวอร์ชัน MeshMill, เวอร์ชัน Windows, รุ่น GPU, การนับสามเหลี่ยมแบบตาข่าย, การดำเนินการที่แน่นอน
ลำดับ และไม่ว่าจะใช้ตัวติดตั้งหรือแพ็คเกจแบบพกพาหรือไม่ ใช้ตัวอย่างที่สามารถแจกจ่ายต่อได้
ตาข่ายเมื่อเป็นไปได้ อย่าแนบการสแกนส่วนตัวหรือบันทึกการวินิจฉัยโดยไม่ได้ตรวจสอบก่อน
