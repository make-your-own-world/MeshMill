# Política de segurança

## Versões suportadas

As correções de segurança são aplicadas à última versão publicada do MeshMill.

## Relatando uma vulnerabilidade

Use o recurso de relatório de vulnerabilidade privada do GitHub quando estiver habilitado para o repositório. Não
incluem arquivos de malha privados, credenciais, logs de diagnóstico ou informações pessoais, a menos que sejam
obrigados a reproduzir o problema e sua divulgação foi explicitamente aprovada.

Inclua a versão afetada, o sistema operacional, as etapas de reprodução e o impacto esperado. Público
problemas são apropriados para bugs comuns que não expõem dados ou criam um limite de segurança
fracasso.
