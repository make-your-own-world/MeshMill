# Tástáil algartam agus ranníocaíocht

Ba cheart go mbeadh an chéimseata dheacair inbhainistithe le halgartaim MeshMill agus a n-éifeachtaí a choinneáil infheicthe,
intomhaiste, agus inchúlaithe sula gcuirtear toradh i bhfeidhm.

## Daingneáin tagartha

Úsáid an dá leagan cuachta den chéimseata samplach ilchodach:

- Is é `samples/sample-scan.stl` an daingneán gnáth-Git níos lú le haghaidh gnáthfhorbairt, uathoibrithe
  seiceálacha, agus na rialuithe a fhoghlaim.
- Is é `samples/original-scan.stl` an daingneán iomlán Git LFS le haghaidh iompar mórchomhaid, sraitheanna iomarcacha,
  dlús míchothrom, forluí, agus obair feidhmíochta.

Is saintréithe tástála d’aon ghnó iad na réigiúin iomarcacha agus dlúth. Féadfaidh tástáil díriú orthu, ach
níor cheart glacadh leis go bhfuil gach dromchla forluiteach indiúscartha. Cuir mogaill shintéiseacha dhlúth leis nuair a
Teastaíonn athrú teorann, cuaire, topology, dlús nó forluí atá ar eolas ag athrú.

## Seicliosta comparáide

Le haghaidh algartam nó athrú paraiméadar, taifead:

- Leagan MeshMill nó tiomantas;
- daingneán ionchuir agus seiceála;
- algartam, réamhshocruithe cáilíochta, sprioc, agus ardsocruithe;
- comhaireamh triantáin agus rinn bhunaidh agus dá bharr;
- céatadán laghdaithe, toisí, agus sruth toisí;
- am caite agus buaicchuimhne nuair a bhíonn an fheidhmíocht ábhartha;
- screenshots ó na radharcanna agus na modhanna taispeána céanna a shábháil;
- teorainn infheicthe, poll, féin-thrasnaíonn, forluí, nó athruithe saobhadh;
- cibé acu ar tháinig an toradh ó oibríocht mogall iomlán nó roghnú-amháin.

Déan comparáid idir an t-iompar reatha ag an sprioc chéanna, ní hamháin i gcoinne réamhshocraithe eile le a
comhaireamh aschuir éagsúla. Iniúchadh a dhéanamh ar thaispeántais scáthaithe, dlúis, sreangfhráma agus rinn nuair is cuí.

## Treoir glactha

Ba cheart go seachnódh athrú barrfheabhsaithe athruithe toise gan choinne, inbhéartú dromchla soiléir,
scoilteanna idir réigiúin phróiseáilte, cailliúint teorainneacha brí, agus aischéimnithí móra cáilíochta ag a
comhaireamh aschuir den chineál céanna. Ba cheart go léireodh athruithe atá dírithe ar dhlús gur baineadh an tiúchan as
gan cuaire nó topology úsáideach a iompar.

Ba cheart go n-aithneodh torthaí feidhmíochta an próiseálaí, cumas cuimhne, crua-earraí grafaicí, oibriúcháin
córas, méid an ionchuir, agus cibé an raibh na sonraí i dtaisce cheana féin. Bailíochtú struchtúrach agus screenshots
tacú le hathbhreithniú ach ná cuir in ionad an chigireachta a dhéanann rannchuiditheoirí atá eolach ar an gcéimseata foinse.

## Tástálacha aischéimnithí

Is fearr tástálacha cinntitheacha le lamháltais shoiléire. Coinnigh daingneáin nua beag go leor le haghaidh Git gnáth,
doiciméad a dhéanamh ar a mbunús agus a gceadúnas, agus úsáid a bhaint as céimseata shintéiseach nuair nach bhfuil gá le fíorshonraí foinse.
Ba cheart go gclúdódh tástálacha cealú agus athchóiriú staide nuair is féidir le hoibríocht an chéimseata a mhodhnú.
