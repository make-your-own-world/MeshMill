# Bogearraí tríú páirtí

Braitheann MeshMill ar na bogearraí seo a leanas. Coinníonn na comhpháirteanna seo a gceadúnais féin agus
fógraí cóipchirt.

| Comhpháirt | Leagan | Ceadúnas |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | Python Ceadúnas Fondúireacht Bogearraí |
| [UimhPy](https://numpy.org/) | 2.5.3 | BSD-3-Clásal agus ceadúnais cheadaithe cuachta |
| [tapa-simpliú](https://github.com/pyvista/fast-simplification) | 0.2.0 | MIT |
| [VTK](https://vtk.org/) | 9.7.1 | BSD-3-Claus |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0-amháin, GPL-2.0-amháin, nó GPL-3.0-amháin |
| [Shiboken6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0-amháin, GPL-2.0-amháin, nó GPL-3.0-amháin |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0-nó-níos déanaí le heisceacht bootloader |

Dáileann an beart Windows PySide6 agus Shiboken6 faoina rogha GPL-3.0, comhsheasmhach
le ceadúnas GPL-3.0-nó-níos déanaí MeshMill. Cuimsíonn rothaí NumPy breise ceadúnaithe
comhpháirteanna; tá a bhfógraí san áireamh i meiteashonraí an phacáiste suiteáilte agus ba cheart iad a choinneáil
nuair a athdháileadh beart dénártha modhnaithe.
