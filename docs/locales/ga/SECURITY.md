# Beartas slándála

## Leaganacha tacaithe

Cuirtear socruithe slándála i bhfeidhm ar an eisiúint MeshMill is déanaí a foilsíodh.

## Leochaileacht a thuairisciú

Úsáid gné tuairiscithe leochaileachta príobháideach GitHub nuair atá sé cumasaithe don stór. Ná déan
comhaid mhogall príobháideacha, dintiúir, logaí diagnóiseacha, nó faisnéis phearsanta a áireamh mura bhfuil siad
chun an tsaincheist a atáirgeadh agus tá a nochtadh ceadaithe go sainráite.

Áirigh an leagan lena mbaineann, an córas oibriúcháin, na céimeanna atáirgthe agus an tionchar a bhfuiltear ag súil leis. Poiblí
1083/2006 ón gComhairle tá saincheisteanna iomchuí do ghnáthfhabhtanna nach nochtar sonraí nó nach gcruthaíonn teorainn slándála
teip.
