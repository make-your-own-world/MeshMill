# Política de seguridad

## Versiones compatibles

Las correcciones de seguridad se aplican a la última versión publicada de MeshMill.

## Informar una vulnerabilidad

Utilice la función de informes de vulnerabilidad privados de GitHub cuando esté habilitada para el repositorio. No
incluir archivos de malla privados, credenciales, registros de diagnóstico o información personal a menos que sean
obligados a reproducir la edición y su divulgación ha sido expresamente aprobada.
