# Registro de cambios

Todos los cambios de lanzamiento notables están documentados aquí.

## 0.1.0

- Conectó el botón GitHub de la aplicación al repositorio MeshMill.
- Se agregaron enlaces de GitHub y Cómprame un café al cuadro de diálogo Acerca de.
- Se agregó carga, inspección, selección, recorte, eliminación, optimización y exportación local de STL.
- Se agregó Fast QEM, optimización de densidad equilibrada, preservación de forma y preservación de topología.
- Se agregaron modos de visualización de vértices, densidad, estructura alámbrica y sombreado.
- Se agregaron operaciones en segundo plano cancelables, comparaciones en caché, deshacer y rehacer.
- Se agregó calibración de vista estándar con vistas opuestas emparejadas y accesos directos configurables.
- Se agregó verificación previa de memoria de malla grande y carga de descripción general limitada.
- Se agregaron métricas de rendimiento Windows, empaquetado portátil, empaquetado del instalador y operación CLI.
- Se agregaron catálogos de localización y herramientas de colaboración para futuras traducciones.
