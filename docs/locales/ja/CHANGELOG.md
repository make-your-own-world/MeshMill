# 変更履歴

重要なリリース変更はすべてここに文書化されています。

## 0.1.0

- アプリケーションの GitHub ボタンを MeshMill リポジトリに接続しました。
- GitHub と Buy Me a Coffee のリンクを About ダイアログに追加しました。
- ローカルの STL の読み込み、検査、選択、トリミング、削除、最適化、エクスポートが追加されました。
- Fast QEM、密度バランス、形状保持、トポロジ保持の最適化を追加しました。
- シェーディング、密度、ワイヤーフレーム、頂点の表示モードが追加されました。
- キャンセル可能なバックグラウンド操作、キャッシュされた比較、元に戻す、やり直しが追加されました。
- 対になった反対側のビューと構成可能なショートカットを使用した標準ビューのキャリブレーションが追加されました。
- 大規模メッシュ メモリのプリフライトと制限された概要の読み込みが追加されました。
- Windows パフォーマンス メトリクス、ポータブル パッケージ化、インストーラー パッケージ化、および CLI 操作を追加しました。
- 将来の翻訳のためにローカリゼーション カタログとコントリビューター ツールを追加しました。
