# トラブルシューティング

## Windows はダウンロードをブロックします

未署名のコミュニティ ビルドにより、Microsoft Defender SmartScreen がトリガーされる可能性があります。ダウンロードしたものを比較する
ファイルの SHA-256 ハッシュと同じ GitHub リリースの `SHA256SUMS.txt`。署名されたリリースは識別します
Windows ファイルのプロパティの発行者。

## ポータブル ビルドが開始されない

`MeshMill.exe` を実行する前に、完全な ZIP を解凍してください。 `_internal` ディレクトリは次に残しておく必要があります
両方の実行可能ファイルに。 ZIP ビューア内から実行可能ファイルを実行しないでください。

## 大きな STL が概要として開きます

推定されたワーキング セットが設定のメモリ バジェットを超えています。概要モードは意図的に
読み取り専用。マシンに十分なメモリがある場合にのみバジェットを増やすか、メモリの量を減らしてください。
編集のために開く前にメッシュを作成します。

## 標準ビューが保存されませんでした

Ctrl キーを押しながらビューのショートカットを押し、**保存** を選択するか、確認メッセージで Enter キーを押します。
ダイアログ。 1 つのビューを保存すると、反対側のビューも更新されます。ステータス行は保存されたビューを報告します。

## ナビゲーションショートカットが反応しない

まずモーダル ダイアログを閉じます。カスタマイズされている場合は、[設定] でショートカットを確認またはリセットします。の
デフォルトのビューのショートカットでは、挿入、ホーム、Page Up、削除、End、および Page Down が使用されます。

## ローカル方向診断ログを作成する

診断ログはデフォルトでは無効になっています。キーボードのルーティングとカメラの状態をローカルに記録するには:

```powershell
.\MeshMill.exe --diagnostic-log ".\orientation-session.jsonl" "C:\path\mesh.stl"
```

ログには、開かれたファイルのパスが含まれる場合があります。共有する前に確認して編集してください。メッシュ ジオメトリはありません
ログに書き込まれます。

## 問題を報告する

MeshMill バージョン、Windows バージョン、GPU モデル、メッシュ三角形数、正確なアクションを含む
シーケンス、およびインストーラーまたはポータブル パッケージが使用されたかどうか。再配布可能なサンプルを使用する
可能であればメッシュを使用します。最初に確認せずにプライベート スキャンや診断ログを添付しないでください。
