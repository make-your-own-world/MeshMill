MeshMillは、巨大、高密度、あるいは複雑なメッシュジオメトリを
扱いやすくするための、機能に特化したデスクトップアプリケーションです。高速な検査、密度解析、領域選択、クロッピング、削除、
そして制御されたメッシュ削減といった機能を、アカウント作成やジオメトリのアップロードなしで利用できます。

GPU アクセラレーションによる OpenGL レンダリングにより、ビューポートのナビゲーション、ハードウェアの選択、密度の視覚化、
インタラクティブな検査に対応します。メッシュ削減は現在、別個のネイティブ CPU ワーカーで実行されています。
長いジオメトリ計算をインターフェイスから遠ざけます。

MeshMillは、3Dスキャナー、CADやモデリングソフトからのエクスポートデータ、再構築パイプライン、
生成されたジオメトリ、その他のSTLソースからのメッシュに対応しています。後続の編集ツール、
製造ツール、その他のメッシュワークフローで使用するためのジオメトリを準備します。汎用モデリング、スカルプト、アニメーション、
マテリアル設定、シーン作成などは対象外です。

## ダウンロード

[GitHub Releases](../../releases)から、以下のいずれかのファイルをダウンロードしてください：

- `MeshMill-<version>-windows-x64-setup.exe`：ユーザーごとのインストーラー（スタートメニューおよびオプションの
  デスクトップショートカット作成機能付き）。
- `MeshMill-<version>-windows-x64-portable.zip`：ポータブルアプリケーション。アーカイブ全体を解凍し、
  `MeshMill.exe`を実行してください。

どちらのパッケージにもアプリケーションのランタイムが含まれています。エンドユーザーが Python、Node.js、または
依存関係。安定版リリースは、x64 ハードウェア上の Windows 10 および Windows 11 をサポートします。

未署名の Linux x86-64 および macOS Intel/Apple シリコン プレビュー パッケージもリリースに含まれる場合があります。
これらは、GitHub でホストされるネイティブ ランナー上に構築されており、パッケージ化された CLI とサンプルメッシュのスモーク テストに合格します。
ただし、実際のハードウェアでのテストが必要です。 [Linux および macOS のプレビュー テスト](../../PLATFORM_TESTING.md) を参照してください。
インストールまたは結果を報告する前に。

未署名のコミュニティ ビルドでは、Windows SmartScreen または macOS Gatekeeper の警告が表示される場合があります。リリース
チェックサムは各リリースの横にリストされています。

## クイックスタート

1. STL を開きます。
2. シェーディング、密度、ワイヤーフレーム、または頂点表示モードで確認します。
3. 品質レベル、アルゴリズム、および目標三角形数を選択します。
4. **Optimize**（最適化）を選択して結果を計算します。
5. 元のメッシュと最適化されたメッシュを比較し、**Apply**（適用）を選択して処理を確定します。
6. **Save current state**（現在の状態を保存）を選択するか、`Ctrl+S` を押します。

ファイルや設定が変更されたという理由だけで MeshMill が最適化を開始することはありません。

## 機能

- バイナリおよびASCII形式のSTL入力、バイナリ形式のSTL出力
- Fast QEM：密度バランス、形状維持、およびトポロジ維持を考慮した削減
- GPU で高速化された OpenGL ビューポート、ハードウェア選択、密度の視覚化
- メッシュ削減のためのネイティブ バックグラウンド ジオメトリ ワーカー
- シェーディング、密度、ワイヤーフレーム、頂点表示モード
- 固定の三角形数上限ではなく、ジオメトリに基づいた自動ターゲット設定
- ポリゴン選択（複数領域の追加選択に対応）
- 選択領域のみの切り抜き（クロップ）、削除、または最適化
- キャッシュされた「オリジナル」「直前」「現在」のメッシュ比較
- 確定したジオメトリ変更の「元に戻す（Undo）」および「やり直し（Redo）」
- 寸法のずれ、削減率、および推定出力サイズ
- 表示単位：ミリメートル、センチメートル、メートル、インチ、フィート
- CPU、メモリ、GPU、およびジオメトリ処理に関するメトリクス
- バイナリSTLが設定メモリ制限を超える場合の、範囲を限定した概要読み込み
- GUIおよびコマンドラインアプリケーション
- ローカル処理（アカウント、テレメトリ、アップロード、クラウドへの依存なし）

## 縮小する前にジオメトリを検査する

シェーディング表示により、表面とシルエットがきれいに表示されます。比較するのに便利です
最適化パスを適用する前に形状を保持します。

![バンドルされたサンプル メッシュを示す MeshMill シェーディング ビューポート](../../images/meshmill-shaded.png)

頂点表示には、実際のポイント分布が表示されます。密なスキャン領域、まばらな領域、
サンプリングの突然の変化は、ジオメトリを変更せずに表示されます。拡張されたメトリクスパネル
メッシュの操作中に CPU、メモリ、GPU、ジオメトリ処理アクティビティを追跡します。

![拡張されたパフォーマンス メトリクスを含む MeshMill 頂点表示](../../images/meshmill-vertices.png)

ワイヤーフレーム表示は三角形構造を直接表示します。不必要な密度を特定するのに役立ちます。
不規則な三角形分割、および単純化によって実質的なジオメトリが削除される可能性がある領域。

![三角形密度の変化を示すメッシュミル ワイヤーフレーム表示](../../images/meshmill-wireframe.png) (MeshMill)

## メッシュ密度を分析する

密度表示は、モデル全体の相対的な局所密度をマップします。まばらな地域は涼しいままですが、
密度が高くなるほど領域が明るい色に変化し、不均一なサンプリングが一目でわかるようになります。

![相対メッシュ密度を示すメッシュミル密度表示](../../images/meshmill-density.png) (MeshMill)

暫定的な最適化を評価している間、密度は引き続き利用できます。ツールボックスは次のことを報告します。
アルゴリズム、ターゲット、結果として得られる三角形と頂点の数、削減パーセンテージ、寸法、
パスが適用される前の推定出力サイズ。

![暫定的な最適化を示すメッシュミル密度表示](../../images/meshmill-density-overview.png) (MeshMill)

マウスの右ボタンを押したままにして、円形拡大鏡を通して領域を検査します。拡大図
はポインタの中心に留まり、メイン カメラの位置を変更せずに局所的な密度を明らかにします。

![ビューポート拡大鏡によるメッシュミル密度表示](../../images/meshmill-density-zoom.png) (MeshMill)

## 選択ワークフロー

Ctrl キーを押しながら左ドラッグして多角形を描きます。角をドラッグして形状を変更し、エッジを左クリックして追加します。
ポイントを選択するか、エッジを右クリックしてエッジを削除します。 `Ctrl+C` を使用してリージョンをさらに追加します。カメラを移動すると非表示になります
選択したジオメトリを保持したまま、スクリーン空間のポリゴンを作成します。

アクティブな選択を使用した最適化は、その選択のみに影響します。結果は暫定的なままです
**適用**が選択されるまで。 **キャンセル** は暫定結果を破棄し、選択内容を保持します。
別の構成を試すことができます。トリミングと削除の操作は、通常の取り消し可能なメッシュ編集になります。

選択パネルには、選択された頂点、三角形、メッシュ共有、推定値の累積が報告されます。
サイズと寸法。そのアクションは、保持されたデータをトリミング、追加、最適化、削除、ステップバック、またはクリアします。
周囲のジオメトリを隠さずに選択できます。

![保持された領域選択とそのジオメトリ統計を示す MeshMill](../../images/meshmill-crop-selection.png)

## コマンドライン

`MeshMillCLI.exe` は両方のリリース パッケージに含まれています。

```powershell
.\MeshMillCLI.exe "C:\path\mesh.stl" --preset balanced
.\MeshMillCLI.exe "C:\path\mesh.stl" --target 150000 --output "C:\path\mesh-reduced.stl"
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm density --target 150000
.\MeshMillCLI.exe "C:\path\mesh.stl" --algorithm topology --overwrite
```

すべてのオプションに対して `.\MeshMillCLI.exe --help` を実行します。 MeshMill は入力ファイルの上書きを拒否します。

## サンプル形状

開発サンプルには 2 つのバージョンが用意されています。 The sample is a composite mesh with
冗長なジオメトリとさまざまな密度の意図的なレイヤー。スキャナーを持たない人々に、
アルゴリズムの比較、密度の検査、地域操作の実行のための現実的な設備
そしてロードマップ機能の開発。 MeshMill はスキャン入力を必要としません。

|ファイル |三角形 |サイズ |配送 |こんな方に最適 |
| --- | ---: | ---: | --- | --- |
| [`sample-scan.stl`](../../../samples/sample-scan.stl) | 249,999 | 11.9 MiB |通常の Git |迅速な評価、CI、およびコントロールの学習 |
| [`original-scan.stl`](../../../samples/original-scan.stl) | 4,126,315 | 196.8 MiB | Git LFS |高密度のソース ジオメトリと大規模メッシュのパフォーマンスをテストする |

小さいサンプルは、通常のクローンごとにダウンロードされます。変更されていないオリジナルはオプションであり、
Git LFS を通じて管理されるため、通常のリポジトリ履歴が膨張することはありません。 GitHub デスクトップの内容
Git LFS。コマンドライン ユーザーは、Git LFS をインストールして次を実行できます。

```powershell
git lfs pull --include="samples/original-scan.stl"
```

タグ付きリリースでは、Git を使用しない人向けの直接ダウンロードとしてオリジナルの STL も公開されています。
来歴、寸法、チェックサムについては、[`samples/README.md`](../../../samples/README.md) を参照してください。

アルゴリズムの貢献者は以下も読む必要があります。
リダクションを比較または変更する前に [アルゴリズム テスト ガイド](docs/ALGORITHM_TESTING.md)
行動。

クラウド処理機能。現在の GPU メトリクスの実装では、ローカルの Windows パフォーマンスが使用されます。
カウンター。同等のネイティブ メトリクス プロバイダーが Linux および macOS に対して計画されています。

診断トラブルシューティングの場合、開発者は次のコマンドを使用して GUI を起動できます。
