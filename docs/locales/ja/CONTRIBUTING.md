## ローカリゼーション

英語の UI ソース テキストは `locales/en-US.json` に格納されます。ロケールメタデータは次の場所に保存されます
`locales/manifest.json`。翻訳された UI カタログは同じ安定したキーとファイル名を使用します
`<locale>.json`。翻訳されたドキュメントでは、一致するルート ファイル名が使用されます。
`docs/locales/<locale>/`。

ラベル、ツールチップ、ダイアログ、またはその他のユーザーに表示されるテキストを変更した後、次のコマンドを実行します。

```powershell
python tools/localization/extract_ui_catalog.py
python tools/localization/validate_locales.py
```

ソースの変更と再生成されたキーを一緒に確認します。

## 開発セットアップ

1. 64 ビット Python 3.12 を Windows にインストールします。
2. 仮想環境を作成してアクティブ化します。
3. `requirements-dev.txt`をインストールします。
4. GUI の場合は `python meshmill.py` を実行し、CLI の場合は `python meshmill.py --help` を実行します。
5. 変更を送信する前に、`python -m py_compile meshmill.py` を実行してください。

プライベート メッシュ、生成された実行可能ファイル、プライベート情報を含むスクリーンショット、およびローカルを保持します。
