# برامج الطرف الثالث

يعتمد MeshMill على البرنامج التالي. تحتفظ هذه المكونات بتراخيصها و
إشعارات حقوق النشر.

| المكون | النسخة | الترخيص |
| --- | ---: | --- |
| [Python](https://www.python.org/) | 3.12 | ترخيص مؤسسة البرمجيات Python |
| [نومبي](https://numpy.org/) | 2.5.3 | BSD-3-بند والتراخيص المسموح بها المجمعة |
| [التبسيط السريع](https://github.com/pyvista/fast-simplification) | 0.2.0 | معهد ماساتشوستس للتكنولوجيا |
| [VTK](https://vtk.org/) | 9.7.1 | بسد-3-بند |
| [PySide6](https://doc.qt.io/qtforpython-6/) | 6.11.2 | LGPL-3.0 فقط، GPL-2.0 فقط، أو GPL-3.0 فقط |
| [شيبوكين6](https://doc.qt.io/qtforpython-6/shiboken6/) | 6.11.2 | LGPL-3.0 فقط، GPL-2.0 فقط، أو GPL-3.0 فقط |
| [PyInstaller](https://pyinstaller.org/) | 6.22.3 | GPL-2.0 أو الأحدث مع استثناء أداة تحميل التشغيل |

تقوم حزمة Windows بتوزيع PySide6 وShiboken6 ضمن خيار GPL-3.0، بشكل متسق
مع ترخيص MeshMill GPL-3.0 أو الأحدث. تحتوي عجلات NumPy على ترخيص إضافي
المكونات؛ يتم تضمين إشعاراتها في بيانات تعريف الحزمة المثبتة ويجب الاحتفاظ بها
عند إعادة توزيع حزمة ثنائية معدلة.
