# سجل التغيير

تم توثيق جميع تغييرات الإصدار الملحوظة هنا.

## 0.1.0

- تمت إضافة تحميل STL المحلي والفحص والاختيار والاقتصاص والحذف والتحسين والتصدير.
- تمت إضافة Fast QEM وتحسين توازن الكثافة والحفاظ على الشكل والحفاظ على الهيكل.
- تمت إضافة أوضاع العرض المظللة والكثافة والإطار السلكي والقمة.
- تمت إضافة عمليات الخلفية القابلة للإلغاء والمقارنات المخزنة مؤقتًا والتراجع والإعادة.
- تمت إضافة معايرة العرض القياسي مع طرق عرض متقابلة مقترنة واختصارات قابلة للتكوين.
- تمت إضافة الاختبار المبدئي لذاكرة الشبكة الكبيرة وتحميل نظرة عامة محدودة.
- تمت إضافة مقاييس أداء Windows والتعبئة المحمولة وتغليف المثبت وتشغيل CLI.
- تمت إضافة كتالوجات الترجمة وأدوات المساهمة للترجمات المستقبلية.
