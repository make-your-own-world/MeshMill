# السياسة الأمنية

## الإصدارات المدعومة

يتم تطبيق إصلاحات الأمان على أحدث إصدار MeshMill المنشور.

## الإبلاغ عن ثغرة أمنية

استخدم ميزة الإبلاغ عن الثغرات الأمنية الخاصة بـ GitHub عند تمكينها للمستودع. لا
تضمين ملفات الشبكة الخاصة أو بيانات الاعتماد أو سجلات التشخيص أو المعلومات الشخصية ما لم تكن كذلك
مطلوبًا لإعادة إنتاج المشكلة وتمت الموافقة على الكشف عنها بشكل صريح.

قم بتضمين الإصدار المتأثر ونظام التشغيل وخطوات إعادة الإنتاج والتأثير المتوقع. عام
تعتبر المشكلات مناسبة للأخطاء العادية التي لا تكشف البيانات أو تنشئ حدودًا أمنية
الفشل.
