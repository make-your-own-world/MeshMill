# Politique de sécurité

## Versions prises en charge

Les correctifs de sécurité sont appliqués à la dernière version publiée de MeshMill.

## Signaler une vulnérabilité

Utilisez la fonctionnalité de rapport de vulnérabilité privée de GitHub lorsqu'elle est activée pour le référentiel. Ne pas
inclure des fichiers de maillage privé, des informations d'identification, des journaux de diagnostic ou des informations personnelles, sauf s'ils sont
requis pour reproduire le numéro et leur divulgation a été explicitement approuvée.

Incluez la version concernée, le système d’exploitation, les étapes de reproduction et l’impact attendu. Publique
les problèmes sont appropriés pour les bogues ordinaires qui n’exposent pas de données ou ne créent pas de limite de sécurité
échec.
