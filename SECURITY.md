# Security policy

## Supported versions

Security fixes are applied to the latest published MeshMill release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is enabled for the repository. Do not
include private mesh files, credentials, diagnostic logs, or personal information unless they are
required to reproduce the issue and their disclosure has been explicitly approved.

Include the affected version, operating system, reproduction steps, and expected impact. Public
issues are appropriate for ordinary bugs that do not expose data or create a security boundary
failure.
